## Problem and two learning objectives

The paper studies long-context language modeling with a fixed amount of adaptive memory and bounded work per additional token. Its architectural starting point is a Transformer using sliding-window attention. It compresses earlier context into updated MLP weights, and uses meta-learning to make the initial weights suitable for this update process.

“End-to-end” refers to two different objectives:

1. **At test time:** the inner update uses the model's actual next-token cross-entropy loss at the end of the network.
2. **At training time:** the outer update differentiates through the inner updates and minimizes the resulting sequence of causal prediction losses.

This distinguishes the method both from dynamic evaluation of ordinarily pretrained weights and from test-time key/value reconstruction modules. The underlying ideas are explicitly attributed to dynamic evaluation, fast weights and meta-learning; the paper does not claim to originate online gradient-based memory.

### Toy model and causal ordering

Remove all attention layers from a Transformer. The resulting network sees only the immediately preceding token and is a bigram predictor. With model weights \(W\), define

\[
\ell_t(W)=\operatorname{CE}(f(x_{t-1};W),x_t),\qquad
W_t=W_{t-1}-\eta\nabla\ell_t(W_{t-1}).
\]

Here \(x_0\) is BOS. The prediction of \(x_t\) uses \(W_{t-1}\), before the target \(x_t\) enters the update. After observing \(x_1,\ldots,x_T\), prediction of the next token uses \(f(x_T;W_T)\). The weights thereby carry information from earlier tokens despite the absence of attention.

The outer objective is

\[
\mathcal L(W_0;X)=\frac1T\sum_{t=1}^T\ell_t(W_{t-1}),
\]

with each intermediate \(W_{t-1}\) determined by earlier inner updates. It is an average of **pre-update, sequential test losses**, not simply the final training loss after fitting all targets. Ordinary pretraining instead minimizes \(\frac1T\sum_t\ell_t(W_0)\), which ignores adaptation when choosing the initialization. The latter followed by test-time updates is the paper's TTT-naive comparator.

In the toy experiment, two Transformer blocks use dimension 384 and six heads, and training sequences have length 128. Removing attention also removes parameters, so the toy attention and attention-free architectures are not parameter matched. The outer batch is 125K tokens. The learning-rate sweep is 2e−3 through 6e−3 in increments of .5e−3; best rates are 3e−3 for full attention and 5e−3 for the attention-free methods. Figure 2 shows the meta-trained online model approaching full attention, whereas TTT-naive improves much less over the bigram baseline.

### Minibatches and local attention

For batches \(I_i=\{(i-1)b+1,\ldots,ib\}\),

\[
W_i=W_{i-1}-\eta\,\frac1b\sum_{t\in I_i}\nabla\ell_t(W_{i-1}),
\qquad
\mathcal L=\frac1T\sum_i\sum_{t\in I_i}\ell_t(W_{i-1}).
\]

All predictions in a batch use its starting weights. This improves parallelism and stability, but the attention-free toy network cannot remember earlier tokens within that batch; Figure 2's \(b=16\) curve exhibits repeated loss rises. The final method restores sliding-window attention with window \(k\ge b\), so local context is available before a weight update. Default \(k=8\mathrm K\) and \(b=1\mathrm K\).

Three implementation choices matter:

- Update only MLP weights in the inner loop. Embeddings, normalization and attention weights remain fixed there because adapting them caused outer-training instability.
- Update only the last quarter of Transformer blocks. Backpropagation for the inner step stops below this region.
- Add a second, static MLP in each adapted block as a store for pretrained knowledge. Reduce MLP hidden widths throughout the network to keep total parameters comparable.

These are supplied design choices, chosen empirically. The method learns weight values, not the number or symbolic identity of adaptive states.

When generating a long continuation, the model decodes normally until another batch of generated tokens is complete, then trains on that batch and continues. These update labels are the model's own samples, not newly observed external ground truth. Independent test sequences initialize their own adaptive weights; the experiments are not an indefinitely persistent shared model updated across unrelated users.

## Relation to key-value binding and recurrent state

For a TTT-KVB layer, the inner objective is

\[
\ell_t^{(l)}(W)=
\|g(\theta_K^{(l)}x_t^{(l)};W)-\theta_V^{(l)}x_t^{(l)}\|^2.
\]

The standard output evaluates a separate query projection using the newly updated weights. The paper first replaces it by the already computed key prediction at the old weights, eliminating a second evaluation and the separate query projection. With local attention supplying nearby context, this costs about .001 loss in the reported experiment.

Next, the local reconstruction objectives and their key/value projections are removed, and the true next-token loss is backpropagated through the network. Finally, small multi-head/LoRA states in every layer are replaced by larger regular MLP states in fewer upper layers.

| 760M model, DCLM at 8K; Table 1 | Reported loss |
|---|---:|
| SWA baseline | 2.827 |
| Original TTT-KVB | 2.818 |
| Simplified KVB output | 2.819 |
| E2E next-token update, all layers, multi-head | 2.806 |
| Final TTT-E2E | 2.805 |

The authors treat .001 as below their significance threshold. No repeated-run uncertainty estimate is supplied with this table, so that statement should remain their criterion rather than a new statistical test.

For the 760M model, the final construction has **88M adaptive weights versus 18M** in the all-layers multi-head alternative, while measured prefill time falls from .017 to .0086 seconds per 1K tokens on an H100. The explanation is that propagating gradients through large surrounding layers can dominate the cost of updating a small state. Updating fewer, larger states can therefore be more efficient.

Calling the method an RNN is an exact algorithmic viewpoint: adaptive weights are a recurrent variable, and gradient computation specifies its transition. For an actual implementation, the complete continuing state also includes local attention caches, the unfinished batch or equivalent information needed for its update, and counters. The reported adaptive-weight count alone is not a complete installed-memory or working-memory charge. No theorem says the resulting state is minimal, identifiable or sufficient for every future task.

## Experimental setup and comparators

The experiments have two stages: pretraining at 8K context on DCLM-Baseline and extension fine-tuning at the final context length on Books, at most 128K. Documents shorter than 8K are discarded from DCLM to avoid costly resets of adaptive weights when packing multiple documents. This is a material dataset selection. Very long DCLM sequences were judged low quality, motivating Books for extension and held-out language-model evaluation.

The model sizes in Table 3 are 125M, 350M, 760M, 1.3B and 2.7B; prose rounds the largest to 3B. Configurations range from 12 to 32 blocks, widths 768 to 2,560 and 12 to 32 heads. The baseline recipe uses approximately Chinchilla-sized pretraining data and 5% as many extension tokens. Learning uses one epoch, a 10% linear warmup and cosine decay to 1e−5, restarting for extension. The full-attention baseline's extension learning-rate sweep selects 4e−4, then this is shared across methods.

Llama3 tokenization, QK normalization and RoPE are used. Full-attention RoPE theta is 500K at 8K, 1M at 16K, 2M at 32K, 5M at 64K and 10M at 128K. The exact inner-loop learning-rate implementation is not specified by the outer-rate table; it should be taken from an identified code/configuration version when reproducing the experiment.

The six comparators are full attention; SWA; five SWA layers followed by one full-attention layer; Mamba2; Gated DeltaNet; and TTT-KVB. The last three are hybrids with SWA, not pure standalone recurrent layers. All SWA windows are 8K except explicit ablations. Full attention and SWA are identical during 8K pretraining and diverge at longer extension lengths.

The authors implement attention baselines and their own model in JAX and use official PyTorch implementations for the recurrent baselines. They consult baseline authors, upgrade those baselines' attention kernels from FlashAttention2 to FlashAttention3 and add QK normalization. For Gated DeltaNet at 760M, QK norm changes loss from 2.814 to 2.809 at pretraining and 2.691 to 2.683 at 32K extension. These efforts strengthen the comparison, but the training and inference software stacks remain different.

## What the results establish

### Ablations

Larger windows improve all tested methods. The chosen 8K window gives useful quality without a large runtime penalty relative to smaller windows. The text reports an improvement of .018 from TTT even when the local window covers the entire 8K sequence; Table 1 separately reports 2.827 versus 2.805. These are the paper's reported values, not an exactly reconciled single run.

Larger inner minibatches from 1K to 8K hurt both TTT variants; smaller than 1K creates utilization and stability problems. At \(b=T=8\mathrm K\), there is no within-sequence prediction benefit from an update: it occurs after every evaluated target. The modified architectures without useful TTT score 2.825/2.826 versus full attention's 2.827, suggesting the architecture modifications alone explain little of the gain.

For a 24-block 760M model, adapting only one or three blocks loses the approximately flat loss advantage as context grows. Six and twelve updated blocks scale similarly, so the final choice is six, or one quarter. This is an empirical storage/update-cost tradeoff within a supplied architecture, not a general state-size law. The long-context ablation doubles the outer batch size at every context length for a consistent comparison.

### Model size, training tokens and context length

The training-scale experiments vary model size and, separately, tokens for the fixed 760M model up to five times its basic recipe. They report DCLM performance immediately after 8K pretraining and Books performance after 32K extension. Smaller 125M/350M models were unstable at longer extension lengths.

The relative advantage of TTT-E2E over full attention shrinks in the smallest-compute regime and becomes flatter around 760M and about 48B training tokens. Gated DeltaNet shows a related training-scale trend. The expectation that this persists into large production runs is the authors' extrapolation; the largest tested size is approximately 3B.

For the flagship context experiment, **each context length has its own extension-fine-tuned checkpoint** derived from a common pretraining checkpoint. Figure 1 is not one frozen model extrapolating from 8K to 128K without retraining.

Across those checkpoints, the TTT-E2E minus full-attention average loss remains roughly −.01 to −.016 from 8K to 128K, while the other recurrent/SWA baselines fall behind. At 128K, Figure 9 shows approximately 2.25 versus 2.26 loss for TTT and full attention; these are plot-level approximations. No fitted scaling exponent or uniform asymptotic theorem is supplied.

The token-index breakdown in Figure 6 also uses different models at 32K and 128K. Both show lower TTT losses throughout the evaluated interval, but much of the average advantage comes from earlier tokens. Some advantage exists even before the first 1K-token update, so it cannot all be credited to context already stored by test-time training. The authors attribute this to an initialization specialized for imminent predictions, with later adaptation handling later tokens. That is an interpretation, not an isolated causal proof of the explanation.

Switching Llama2 to Llama3 tokenization reportedly improves the 3B relative gap by about .01; newer DCLM/FineWebEdu data also improve token-scaling behavior relative to SlimPajama. The authors label these observations anecdotal and do not supply a full cross-dataset/tokenizer study.

### Exact retrieval is a pronounced failure case

All 3B models for RULER needle tests are the checkpoints extended to 128K. At 128K:

| Task | Full attention | TTT-E2E |
|---|---:|---:|
| Pass-key retrieval | .99 | .06 |
| Number in a haystack | .86 | .05 |
| UUID in a haystack | .64 | .03 |

TTT performs similarly to other compressed-state baselines, with a strong decline beyond the local window. Its average language-model loss advantage does not imply competitive arbitrary-detail recall. The authors explicitly present this as a cost of compressing information that appears irrelevant during ordinary prediction.

### Long generated continuations

The paper prefills 8K Books tokens, generates another 8K, and evaluates the concatenated sequences under Qwen3-8B-Base. The reported curve averages 512 sequences. Temperature is one, top-p .95 and repetition penalty 1.1; the authors manually inspect about twenty generated samples.

TTT-E2E receives lower evaluator cross-entropy than full attention in this experiment. This is likelihood under one external model, not factual accuracy, reasoning quality, diversity or a proof that self-training is stable indefinitely. Instruction tuning and reinforcement learning are absent. Both curves jump at the transition to generated text and then decrease; the authors suggest adaptation to the generated style as an explanation.

## Costs, complexity and important qualifications

For fixed model size, fixed window and fixed inner batch, prefill performs \(O(T)\) work, while full attention performs \(O(T^2)\). Decoding an additional token has bounded context-length dependence, with periodic batch-update costs. Constant cost with respect to \(T\) does not mean a small state or zero training work.

Figure 1 measures **prefill seconds per 1K tokens**, not a complete separately measured generation latency. One H100 processes a fixed 128K-token outer batch: sixteen sequences at 8K, one at 128K. TTT's reported 2.7× advantage at 128K is against full-attention prefill in this configuration. It is not an unconditional 2.7× speedup for arbitrary prompts, batch sizes or autoregressive serving.

For decode, the paper argues that cost is SWA decoding plus a TTT prefill-like update after every full inner batch. It explicitly reports **no separate TTT decode-latency measurement**. Batch boundaries can therefore produce update pauses even though average work is bounded.

Meta-training is substantially more expensive than ordinary training at short context. Figure 8 uses H200 timings to accommodate baseline kernels, although most actual training was on GB200. With fixed 128K tokens per outer batch, TTT is **3.4× slower at 8K** and **1.2× faster at 128K** than full attention. Most pretraining occurs at the shorter length, so inference efficiency is not a claim of lower total training cost.

The outer loop differentiates through gradients and uses checkpointing through time. Its FLOPs per token are approximately bounded as context grows, but measured training time rises between 8K and 32K as checkpointing increases. The available cuDNN attention kernel did not support the required higher derivatives. A suitable kernel and initialization from an ordinarily pretrained Transformer are proposed improvements, not demonstrated fixes in this paper.

Comparisons matched nominal parameters and training tokens, not equal measured training FLOPs or wall-clock budgets.

## Limited independent check and evidence level

The causal index ordering in equations (2), (5) and (6) was checked against the original PDF. Each scored batch uses weights from previous batches; its targets enter only the subsequent update. This supports the stated online scoring protocol, without certifying every implementation detail.

For fixed nonadaptive parameters and \(F_i(W)=b^{-1}\sum_{t\in I_i}\ell_t(W)\), elementary differentiation gives

\[
S_0=I,\qquad
S_i=(I-\eta\nabla^2F_i(W_{i-1}))S_{i-1},\qquad
\nabla_{W_0}\mathcal L=\frac bT\sum_iS_{i-1}^{\mathsf T}\nabla F_i(W_{i-1}).
\]

This independently checks why differentiating the stated outer objective requires derivatives through inner gradients. It does not certify the learned optimum, stability, empirical scaling or a reduction to a minimal predictive state. Optimizing additional slow parameters adds their direct and indirect derivative paths. No numerical training or formal proof replay was used.

The principal empirical claims remain the authors' results. Full reading, an elementary update-identity check, inspection of selected released configuration files and independent experiment replication have different evidentiary scopes.

## Attribution and unresolved questions

Clark et al. (2022), *Meta-learning Fast Weight Language Models*, is explicitly identified as the closest methodological predecessor: chunkwise next-token updates to fast weights with learned initialization. It retains full attention and adds fast weights near the output, so it does not give the same linear-context cost. This source is a historical attribution dependency, not automatically a new full-reading queue item.

Other dependencies include dynamic evaluation, fast weight programmers, MAML, TTT-KVB, DeltaNet/Gated DeltaNet, checkpointing and the published datasets/baseline implementations. Their role and bibliography entries were read; those sources' own full-reading statuses remain separate.

Open questions include broader task performance, long-horizon self-generated updates, update robustness, adaptation from existing large models, full serving memory and latency measurements, and whether the reported context trend persists beyond the tested data and scale. The paper supplies no exact posterior representation or sufficient-statistic result for future learning under uncertainty.

No FP transfer theorem is proposed. The concrete comparison offered by this paper is a supplied neural state whose update is driven by ordinary next-token error and whose initialization is selected through the same update process. Its quality, recall, state size, data exposure and meta-training costs must all be retained when using it as a comparator.
