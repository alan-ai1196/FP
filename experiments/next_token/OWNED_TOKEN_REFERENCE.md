# Complete compact token learner inside ReferenceCompilerRuntime

The indexed input, arbitrary positive SUM/PRODUCT core and untied positive
readout now execute through the existing Runtime's construction, prediction,
observation, commit and newborn-profile boundaries. This is an owned exact
reference integration. It is not an AMP release or a language-quality result.

## 1. Exact represented state and the deferred-gradient proof

Let `O` be a complete committed native origin: the definition, every E/core/W
grid integer, source-reader state, learner cursor and optimizer-step count.
Let `R=((c_1,y_1),...,(c_n,y_n))`, with `0 <= n <= N`, retain every original
causal source point and revealed target in a pending unit. The representation
is `(O,R)`; its decoder is the native learner initialized to `O` and advanced
through exactly those predict/observe events, with no intervening commit.

**Proved under the registered frozen-unit projected-SGD semantics.** This
decoder preserves the complete native learner after every event, not merely
its current prediction or eventual parameter endpoint:

1. At `n=0`, the masters, zero accumulators and both clocks agree by the
   committed-origin decoder already established for the batched reference.
2. No event before the registered commit changes a master. A forecast uses
   `O`'s masters and the actual Runtime-owned source point, independently of
   the pending gradient. The previous pending records remain in the state.
3. Appending `(c,y)` defines exactly the ordinary native gradient addition,
   including every tied embedding/core incidence and all unobserved readout
   rows. It also determines the source-reader successor, learner cursor and
   unit count. No gradient coordinate is identified with zero merely because
   it was not explicitly materialized.
4. At `n=N`, the existing outward binary64 kernel encloses the exact decoder's
   complete gradient. It publishes a grid successor only if every projected
   coordinate belongs to one uniquely determined integer cell. All masters,
   the actual final source point and the optimizer step are then retained.
   An ambiguous cell, nonfinite operation, array cap or uint32 exhaustion is
   `UNRESOLVED`; it cannot publish a rounded guess or a partial block.

This is lazy evaluation of an exact state, not permission to skip an
intermediate observation or numerical relation. Runtime retains and exposes
every observation phase. A future AMP bridge must relate the physical learner
to the decoder at each required boundary; this reference integration does not
establish that relation. Legal complete-state queries may decode a coordinate
or return `UNRESOLVED` under their funded solver limits. The diagnostic full
decoder is caller allocated and has no setter or certificate authority.

Earlier records cannot be replaced by the final context: the source-clock
counterexamples still apply. Profiles may reverse or repeat retained source
points. Their local optimizer clock is separate from each original source
position; attachment changes only the learner clock namespace at a complete
unit boundary.

## 2. Exact complete forecasts and a sound range bound

Prediction evaluates the compact embedding/core using exact rational
operations under the declared reference integer-operation limit. It retains
the core values and represents every output probability by

`(b_y + sum_i W[y,i]*z_i) / (B + sum_i column_sum(W[:,i])*z_i)`.

Every readout master remains in immutable bytes. The integer column reduction
is exact: `V <= 2^20` and each stored uint32 master is less than `2^32`, so the
sum is less than `2^52` and fits signed int64. The lazy output vector has all
V coordinates; producing a specific rational coordinate obeys its declared
integer limit. It is not a target-only or sampled-label forecast.

The range proof explicitly uses the registered categorical token reader.
Every lag has exactly one active token/PAD atom. Thus each embedding channel
is bounded by the maximum of that channel over all tokens and PAD. Positive
SUM/PRODUCT propagation gives a simultaneous conservative upper bound for
every core feature. Complete W-column sums bound the normalizer; W-column
maxima bound every head excess. Source atoms are bounded by one. These bounds
cover all contexts legal under that owned reader, including a larger set of
independent lag choices than actual contiguous histories. They do not claim
the same bound for arbitrary independent real-valued source assignments.

Runtime independently binds the observation to the original retained source
mapping, recomputes the pre-target cache and rejects changed values, clocks,
normalizers or probability decoders. No public helper supplies a target slot,
owned learner state or future history.

## 3. Registration, ownership and precise scope

`TokenProgram` is a compact native graph encoding. Graph budgets count its
full source/SUM/PRODUCT/edge/slot expansion, even though execution avoids
enumerating those atoms and edges. Gamma registers immutable cyclic integer
patterns for complete flattened E/core/W blocks. U fixes the positive bases,
feature count, grid, learning rate and unit size. Different native cores with
the same registered input/readout shapes may be constructed; this is not a
one-graph evaluator or a claim to search the whole native class.

Runtime alone owns ingress, source acquisition, object leases, event/profile
work debits, traces, data uses and atomic publication of live successors.
Commit work is admitted before the numerical solver starts. Target ingress
and the after-observation recipe survive numerical or work refusal. No caller
may commit a partial unit, replace an existing trajectory with a decoded
state, or treat profile labels as fresh ordinary observations.

The new immutable-byte packed encoding streams bounded hex fragments into
an already admitted exact-size buffer. It retains every byte and preserves
the previous identity encoding of bytes. It does not accept mutable NumPy
arrays as authoritative state. The five formerly experimental reference
modules now have one canonical implementation in `fp_reference`; their old
imports are aliases, preserving class identity rather than making a second
implementation. Merely importing Runtime does not load NumPy.

**Decision scope:** successful construction means an actually owned native
reference candidate with the sufficient declared-context range bound.
Successful observation/commit means the exact registered continuation above.
There is no `CERTIFIED_COMPLETE`, search-class closure, persistence, floating
bridge or installation authority. Registrations requesting the unimplemented
token floating/search/persistence/install paths refuse. Existing scoped
releases do not cover this new backend automatically.

Resource scope remains the existing packed-payload/work model. Per-array
element limits and uint32 storage are realization limits, not FP semantics.
The interval proof is conditional on the previously stated IEEE binary64
execution assumptions. Packed state and trace serialization currently repeat
origins; source records still cost O(TL), and the source reader checks history
in O(T). This change removes repeated numerical prefix evaluation during
ordinary observation, not those storage/serialization costs or all quadratic
metadata work. No whole-host/device or full-corpus affordability claim follows.

## 4. Evidence and stopping point

`scripts/audit_owned_token_learner.py` compares the actual Runtime with the
independent literal native evaluator and scalar ordinary learner:

- All 144 four-token histories across unit sizes 1/2/4 and mixed/zero-input/
  zero-core initializers: 576 observations, 1,152 exact label probabilities,
  16,128 pending gradient coordinates and 336 exact grid commits.
- Sixteen newborn profiles: 64 events with reversed and repeated original
  contexts, followed by 32 ordinary candidate continuations. Complete clocks,
  parameters, gradients and source-reader state match.
- Thirteen cache/source/program/clock/registration/decoder refusals; two actual moment
  query coordinates retain their information uses; a distinct native core
  constructs under the same registered Gamma/U shapes.
- Forced grid ambiguity and denied commit work retain the newly revealed
  target and complete pending unit, publish no successor and halt honestly.
- Binary payload checks retain all 1,282 test bytes, bound fragments, preserve
  exact packed extent and refuse insufficient storage/traversal allowance.

The compact evidence is `evidence/minimal/FP_OWNED_TOKEN_LEARNER.json`.
Existing ordinary-event and newborn-profile regression suites also pass.
No corpus, loss, Torch, GPU or old terminal resource job is used here.
