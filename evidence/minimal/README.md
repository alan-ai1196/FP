# Minimal evidence

This directory follows FP's **minimal evidence principle**. It stores compact outputs needed to audit theorem/model-check claims, not full workspaces, caches, datasets, checkpoints, duplicated ZIPs or raw run logs.

The JSON files here are historical evidence associated with the Foundation-R4 theory attack and Reference Compiler pressure test. They do **not** imply the current Reference Compiler implementation is frozen; see `IMPLEMENTATION_STATUS.md`.
