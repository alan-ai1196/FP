# What FP must learn to do

The first test is to predict the next observed token at a useful cost. The broader test is to acquire a computation from experience, reuse it on a previously unseen task and make better decisions within finite resources. These tests refer to specified tasks, interfaces and budgets. A single score cannot certify general intelligence.

## Three claims with different witnesses

| Level | Claim | Evidence required |
|---|---|---|
| A. Predictive competence | A learner improves causal forecasts on an explicitly declared sequence source. | Full-alphabet distributions, the exact update order, held-out loss, strong similarly informed competitors and a resource account. |
| B. Computational emergence | Learning constructs a distinction, transformation or shared intermediate that changes feasible behavior or price. | Initial state and update law, acquisition work, attainable loss and execution cost against a named class. Test duplicate values, relabelings and an ordinary implementation of the same computation. |
| C. General intelligent behavior | Previously acquired structure transfers across a declared family of unfamiliar tasks, including interaction and adaptation. | Task generation and exposure boundaries, finite adaptation allowance, observed decisions and returns, nested comparisons with a fresh learner and an equally budgeted retrieval mechanism. State which task symmetries or interventions the design can distinguish. |

### Predictive experiment

Fix a finite output alphabet $V$, a stream law or identified finite tape, reset convention and score horizon. After observing $x_t$, the learner may update its parameters and memory using the past through $t$. It then publishes $p_t\in\Delta(V)$ before seeing $x_{t+1}$. An implementation might use $s_t=F_{\theta_t}(s_{t-1},x_t)$ and $p_t=G_{\theta_t}(s_t)$. All test-time changes to $\theta$ or the representation are part of the charged learner. Frozen evaluation fixes them. Compare mean $-\log p_t(x_{t+1})$ on the same targets and permissible histories. A full-vector interface and the ability to return a token's exact normalized probability have different communication costs. Report which was measured.

For a stochastic law $P$, expected excess log loss over the true conditional distribution is the mean conditional KL divergence, by expanding the logarithm. On a deterministic supplied tape the loss directly measures that tape. Prior frontier results measured improvement on original text and a failure to pay for one learned membership table on a later block. They constrain particular Level A and B claims. [Prior prospective evidence](EVIDENCE.md#prospective-transfer-to-the-next-training-file-block)

### Interactive experiment

Choose a family of partially observable controlled environments, a distribution or explicitly adversarial schedule of tasks, bounded observations/rewards and a finite horizon $H$. Draw the evaluation task after training under a published split, with its hidden parameters inaccessible. At step $t$ the policy acts using only the observed history, its acquired state and allowed randomness. The environment then generates an observation and reward. Include exploration, planning, tool use, memory updates and any adaptation in the resource account. For a policy $\pi$ write $J_E(\pi)=E[\sum_{t=1}^{H}\gamma^{t-1} r_t]$. A task family, resource limits and a feasible comparator class define an attainable loss or value frontier. Report gap to a feasible policy and, separately, gap to any privileged oracle. One meaningful comparison is how much pretraining reduces the number of new observations or physical work required to attain a fixed return.

A benchmark should include task compositions withheld from training, changes in the task law, and cases where actions change what can subsequently be learned. Define the allowed changes or variation budget before claiming adaptation. Measure transfer against running the same learning algorithm afresh with the same test allowance, and against storing and retrieving prior episodes under the same bytes and lookup costs. A positive comparison on an independent task family measures transfer there. Recovering the world's unique hidden semantics requires additional identifiability assumptions. The discounted return is a task-relative choice, and the task distribution determines which abilities affect it.

A POMDP belief over latent states can be sufficient for a known model. Its dimension, precision, identification cost and planning time remain material. A universal program-weighted environment prior is an alternative way of specifying a distribution. Reference-machine dependence and computability matter when assigning physical budgets. An online regret guarantee concerns its declared comparator, feedback and horizon. A predictive mixture over $m$ accessible sequence models with prior weights $w_j$ pays at most $-\log w_j$ additional cumulative log loss against any one model, since its sequence probability is at least $w_j P_j$. Evaluating or updating every constituent model can still exhaust the budget. These frameworks provide distinct tests. ### A conditional connection between prediction and control

**PROVED.** Consider a true environment $P$ and a model $Q$ on a common observable action–observation–reward trajectory space, with a common initial observation law and horizon $H$. Include the reward in the predicted next outcome. A logging policy $b$ randomizes using observable history alone. Assume absolute continuity, bounded rewards in $[0,1]$, and positive logging probability for each action used by either the comparator or planned policy on histories they can reach under $P$. Let $d_t$ denote the conditional KL between the true and model outcome laws given the history and selected action. For any such target policy $\pi$ define $\rho_t=\prod_{i=1}^t\pi(a_i\mid h_i)/b(a_i\mid h_i)$. Then
$$D(P^\pi\Vert Q^\pi)=\sum_t E_{P,b}[\rho_t d_t].$$
Factor both path probabilities into policy and outcome kernels. The matching policy terms cancel inside the log ratio, giving the sum of conditional KLs under $P,\pi$. Changing measure on each observable history and action supplies the prefix weight. If both target policies have $\rho_t\le C$ on this support and $D(P^b\Vert Q^b)\le\epsilon$, each target divergence is at most $C\epsilon$. With $B_H=\sum_{t=1}^H\gamma^{t-1}$, Pinsker's inequality bounds each return error by $B_H\sqrt{C\epsilon/2}$. Adding the two errors gives policy regret at most $\min\{B_H,\delta+B_H\sqrt{2C\epsilon}\}$ if planning in $Q$ is within $\delta$ of the best policy of the declared class. An action exploration floor $\eta$ gives only $C\le\eta^{-H}$. This is a population statement. Establishing the model KL and paying for exploration and planning are distinct requirements. [Related sequential off-policy evaluation](https://proceedings.mlr.press/v48/jiang16.html)

**FALSIFIED.** Passive predictive accuracy alone ensures good intervention choice. In one step let the logger always play action zero for reward $1/2$. Action one pays zero in one environment and one in another. The logged laws agree exactly. A learner playing action one with probability $q$ has regrets $q/2$ and $(1-q)/2$. Its worst regret is at least $1/4$, attained at $q=1/2$. Likewise, if independent fair labels are assigned to previously unseen task IDs, any memory of other IDs still gives expected correctness $1/2$ on the new ID. Transfer needs structure shared across the declared tasks.

## Representation and resources

A language interface fixes which events receive probabilities. Token IDs provide neither an obligatory internal dictionary nor a free semantic feature. A finite register budget $b$ distinguishes at most $2^b$ persistent codes irrespective of whether a programmer calls them symbols, vectors or programs. Real arithmetic with unbounded precision changes this comparison. Dynamic symbols incur creation, addressing and reclamation costs. Continuous values incur precision and stability costs. Graph, algebraic, program, Bayesian, hierarchical and hybrid descriptions must each specify how an observation can change their internal objects. Reuse requires a witness in the subsequent computation or a measured saving at equal observable behavior. [Definition of value creation](FOUNDATION.md#what-would-count-as-creating-a-value)

For every serious comparison report training observations/passes and adaptation budget, parameter and code bits, live state, peak temporary storage, arithmetic and dependency depth, and bytes moved at the relevant memory levels. Record synchronization, allocation and irregular access when they matter. Name the precision used for parameters, accumulation and verification. An oracle outcome, algebraic operation count, serialized payload and measured end-to-end RTX 3090 run are different evidence. Prefer Pareto comparisons. A scalar resource price requires a stated exchange rate and deployment horizon.

**UNRESOLVED.** Whether a representation can achieve all three levels across a broad task distribution at a defensible physical cost. Individual demonstrations update this question only within their declared comparison class.

## A quantitative limit on learning from a logger

**PROVED.** Consider $H$ binary decisions. A logger takes a specified continuing action with probability $\alpha$ independently at every step. The special terminal branch requires all $H$ continuations. All other endings have mean return $1/2$. On that branch the only reward is Bernoulli$(1/2+\Delta)$ in one environment and Bernoulli$(1/2-\Delta)$ in the other, with $0<\Delta\le1/4$. Earlier observations coincide. An informed policy can choose whether to reach the branch. If the policy learned from data $D$ chooses it with probability $x(D)$, its regrets are $\Delta(1-x(D))$ and $\Delta x(D)$. Averaging these two worlds bounds worst-case expected regret below by $\Delta(1-\mathrm{TV}(D_+,D_-))/2$. For $N$ independent training episodes the KL between datasets is $N\alpha^H\,\mathrm{kl}(1/2+\Delta\|1/2-\Delta)$. Pinsker therefore gives
$$\sup_E E[\mathrm{regret}]\ \ge\ \frac{\Delta}{2}\Big[1-\sqrt{N\alpha^H\,\mathrm{kl}(1/2+\Delta\|1/2-\Delta)/2}\Big]_+.$$
The Bernoulli KL is $2\Delta\log((1+2\Delta)/(1-2\Delta))\le(32/3)\Delta^2$, by integrating $2/(1-u^2)$ up to $2\Delta\le1/2$. Thus $N\le3/(64\alpha^H\Delta^2)$ forces regret at least $\Delta/4$ in one world. Coupling until the first logged special trajectory gives the additional bound $\Delta(1-\alpha^H)^N/2$. The example has only terminal rewards and no discount. Under a protocol recording every full episode, each example costs $H$ transitions. This makes explicit the difference between support and useful finite-sample coverage.

A theory of universal competence also depends on which tasks receive weight. Leike and Hutter give universal-prior constructions that induce strongly different policies and show the weakness of Pareto optimality over all computable environments. FP comparisons must expose the task distribution, test split and resource prices. [Leike and Hutter, Theorems 7 and 18](https://proceedings.mlr.press/v40/Leike15.html) · [Foster et al., distinct offline learning lower bound](https://proceedings.mlr.press/v178/foster22a.html)

## How much log loss can a single action measure?

Fix a categorical interface with $K\ge2$, a forecast floor $0<a<1/K$, $b=1-(K-1)a$ and $L=\ln(b/a)$. A buyer receives one uniformly sampled outcome name $J$ and independently a price $C$ with density $1/(cL)$ on $[a,b]$. It buys if its reported probability $q_J$ reaches the price. A purchase pays $1_{\{Y=J\}}-C$, while passing pays zero. The outcome and report precede the independent menu randomization. All stakes are one.

**PROVED.** For every individual outcome $y$ and admissible report,
$$
E[R(q,y)\mid q,y]=\frac{\ln(q_y/a)-1+Ka}{K L}.
$$
Integrate $(1_{\{y=j\}}-c)/c$ from $a$ to $q_j$ and sum over $j$. The event term gives $\ln(q_y/a)$ and the price terms sum to $1-Ka$. Thus an arbitrary pair of causal forecasts on a fixed outcome sequence has a difference in expected action payoff equal to its log-score difference divided by $K L$. If truth $p$ is admissible, regret from using $q$ is $D_{\rm KL}(p\Vert q)/(K L)$. The expectation is over menus. One sampled menu can reverse a comparison.

**Sharpness with a price for exploration.** Consider every report- and outcome-independent menu offering one named event at a price with a stake in $[0,1]$. The decision is the threshold for the reported probability of that named event. Require every report to purchase each name with probability at least $\epsilon/K$, for $0\le\epsilon\le1$. The largest universal coefficient $\lambda$ such that truthful expected payoff regret dominates $\lambda D_{\rm KL}(p\Vert q)$ is
$$
\lambda_{\max}=\frac{1-\epsilon}{K\ln(b/a)}.
$$
Write $A_j(x)=E[S\,1_{\{J=j,C\le x\}}]$ and $d_j=A_j(b)-A_j(a)$. The extreme report $r^j$ puts $b$ on $j$ and $a$ everywhere else. Compare truth/report pairs $(r^j,r^k)$ and $(r^k,r^j)$ for $j\ne k$. Summing the two regrets cancels every price term and gives $(b-a)(d_j+d_k)$. The two KLs sum to $2(b-a)L$. Summing the pairwise inequalities over all unordered pairs gives $\sum_j d_j\ge K\lambda L$. For each $j$ some report puts $a$ on $j$, so $P(J=j,C\le a)\ge\epsilon/K$. At most $1-\epsilon$ of the offer probability can carry report-sensitive stake, giving the bound. It is attained by putting probability $\epsilon$ at price $a$ and the rest on the log-uniform menu with uniform name. Guaranteed purchases contribute the report-independent amount $\epsilon(1/K-a)$ per outcome. These scales assume a single named event and bounded stake. The binary integral representation of proper scores is classical. Schervish's Theorem 4.2, its appendix proof and Example 5.2 give the threshold-loss representation and the log-score measure. The calculation here fixes the multicategory interface, one-offer budget, probability floor and required feedback coverage. Priority for these restricted extremal statements is unestablished. [Schervish, Annals of Statistics, 1989](https://doi.org/10.1214/aos/1176347398)

**Why purchase feedback matters.** Conditional on a fixed observed context, suppose the outcome is independent of the offer and only a purchased match bit is revealed. A fixed logger $r$ using the original menu buys name $j$ with exposure $e_j=\ln(r_j/a)/(K L)$. Infinite logs identify $p_j$ when $e_j>0$ and only the total mass on the remaining names. A linear contrast $\sum_jp_j d_j$ is identifiable uniformly over outcome laws precisely when $d_j$ is constant on the unexposed names. This follows by moving mass between two unexposed names, and in the other direction by subtracting their common contrast and using the unit total. The log-score comparison sets $d_j=\ln(q_j/q'_j)$. For $K=3$, logger $(b,a,a)$ sees identical feedback in worlds $(a,b,a)$ and $(a,a,b)$. Those two reports have opposite advantages of magnitude $(b-a)\ln(b/a)$. For independent records from the same fixed logger, the one-record KL between two worlds equals $\sum_j e_j\,\mathrm{kl}(p_j\Vert p'_j)$ by conditioning on the menu. Under the mixed exploration menu every $e_j$ is at least $\epsilon/K$. This is an identification theorem for the specified feedback and exogenous outcome.

**What an external hierarchy buys.** Suppose an external process reveals the true path through a fixed full binary tree of the $K$ labels, one branch at a time. Before each next branch, one may offer a ticket on one of its two children. At most one ticket can be offered on the realized path. At a node the buying rule uses its own conditional probability. Offer scheduling and prices may depend on the revealed prefix and external coins, independently of all reports and unrevealed branches. For node $v$ with child leaf counts $m_0,m_1$, put $\sigma=1-Ka$ and
$$
c_v=\ln(1+\sigma/(m_0a))+\ln(1+\sigma/(m_1a)).
$$
The largest coefficient of a pointwise reward $\lambda\ln q_y+k_y$ is $1/\max_y\sum_{v\in{\rm path}(y)}c_v$ in this protocol. To see the local cost, the first child conditional can range from $l=m_0a/(\sigma+(m_0+m_1)a)$ to $u=(\sigma+m_0a)/(\sigma+(m_0+m_1)a)$. Both extremes keep every other conditional split fixed by assigning the outside leaves their floor and giving each child uniform internal weights. Comparing them on one outcome from each child cancels unaffected nodes and bounds the required offer probability at $v$ below by $\lambda[\ln(u/l)+\ln((1-l)/(1-u))]=\lambda c_v$. Such probabilities must sum to at most one on each path. For attainment, allocate unconditional probability $\lambda c_v$ to the first and only offer at each visited node, conditioning the hazard on having made no earlier offer. Within the node, use a threshold density proportional to $1/c$ for each child on its own feasible interval, with total probability proportional to the log ratio of that child's endpoints. The same integral gives $\lambda$ times its log conditional up to a child-dependent constant. Adding along the realized path yields the leaf log score by the chain rule. If $K=2^d$, the balanced tree is optimal over such trees. A longest path has at least $d$ edges. At its $k$th node above the leaf, neither child has more than $2^{k-1}$ leaves, bounding the path cost below by the balanced sum $2\sum_{i=0}^{d-1}\ln(1+\sigma/(2^i a))$. This advantage uses early, externally supplied outcome information. The text experiment discloses membership in a four-word group before the action. ## What can an unknown decision lose when a state discards information?

Fix finite local components $v$, observation alphabets $R_v$ and encoders $\phi_v:R_v\to S_v$. In a one-stage decision a context $e$ is drawn with weight $w_e>0$ and a joint law $\mu_e$ supplies a hidden outcome $Y_e$ and the raw observations $(R_v)_{v\in e}$. The weights sum to one. Each participating component chooses an action using its own observation and its own identity. Its policy is the same in every context containing that component. There is no communication or shared information about which other components were selected. The loss table $\ell_e(y,a_e)\in[0,1]$ may change between tasks. The context weights, observation laws and access pattern are held fixed. Let $V_{\rm raw}(\ell)$ and $V_\phi(\ell)$ be minimum expected losses with raw or encoded local inputs. The learner can select a policy for each revealed loss table.

Let $k=(k_v:S_v\to R_v)_v$ range over deterministic tuples. A distribution $\lambda$ over these tuples is shared across contexts and independent of all observations. Simulate raw observations by applying a sampled tuple to the encoded inputs while retaining the actual hidden outcome. Its context law is
$$
\nu_e^\lambda=\sum_k\lambda_k(\mathrm{id}_{Y_e},(k_v\circ\phi_v)_{v\in e})_\#\mu_e .
$$

**PROVED.** With total variation equal to half the $\ell_1$ distance, the worst decision loss from this compression is
$$
D_\phi(\mu)=\sup_{A_v,\,0\le\ell_e\le1}\big[V_\phi(\ell)-V_{\rm raw}(\ell)\big]
           =\min_\lambda\sum_e w_e\,\mathrm{TV}(\mu_e,\nu_e^\lambda).
$$
For any raw policy $f$, composing $f$ with the local reconstructions gives a distribution over feasible coarse policies. Their average loss exceeds the raw loss by at most the weighted TV on the right. At least one deterministic coarse policy does as well as the average. Conversely, allow each component to report a raw ID as its action. On the raw side reporting the identity is feasible. On the coarse side the possible randomized report laws are exactly the convex hull of the displayed simulations. Finite minimax interchanges a supremum over the unit cube of losses and a minimum over the decoder simplex in $\sum_e w_e\langle \nu_e^\lambda-\mu_e,\ell_e\rangle$. Maximizing over the loss cube gives precisely the sum of TV distances. These two inequalities prove equality. A dual-optimal loss is a task attaining the bound, with raw identity reporting optimal for that task. Randomness is needed in the *comparison*. For example, reconstructing a fair raw bit from a constant when the outcome is also constant has zero deficiency, but any single deterministic reconstruction has TV $1/2$.

This is a finite decision-theoretic use of deficiency, the randomization theorem and coordinated garblings in common-interest games. Van Rooyen and Williamson already apply deficiency to generic learned features for one decision maker. Lehrer, Rosenberg and Shmaya characterize the exact common-interest information order through mixtures of local garblings. Jenčová’s conversion-distance Theorem 2(iii) specializes directly to this result. Use the fixed-weight joint alphabet of context, outcome and local observations, and take mixtures of local postprocessings preserving context and outcome as the allowed maps. Its classical base norm is twice TV. This gives an existing mathematical foundation for the FP comparison, including a direct witness for a discarded distinction. [Jenčová, Theorem 2](https://arxiv.org/pdf/2002.04240) · [Van Rooyen and Williamson, Theorem 1 and appendix](https://arxiv.org/pdf/1402.4884) · [Lehrer, Rosenberg and Shmaya](https://www.math.tau.ac.il/~lehrer/Papers/signaling%20common.pdf) · [Hogeboom-Burr and Yüksel](https://arxiv.org/abs/2206.12048)

With fixed finite action alphabets the answer remains exact after replacing identity reconstruction by the directed distance between the attainable *action* laws. Let $\mathcal P_R,\mathcal P_S$ be the convex hulls of joint laws of hidden outcomes and actions under the two policy families, using the declared context weights. Then the largest gap is $\max_{P\in\mathcal P_R}\min_{Q\in\mathcal P_S}\mathrm{TV}(P,Q)$, enclosing context as an observed coordinate of the law. Indeed maximizing over $P$ and over $\ell$ commutes, and finite minimax for fixed $P$ gives its distance. If $Y=R$ is uniform on four symbols and $S$ is constant, the unrestricted gap is $3/4$. With just two actions, the most frequent optimal raw action covers at least half the observations, giving gap at most $1/2$. A binary partition of equal masses attains it. For a single forecaster with the usual unbounded logarithmic score the exact raw advantage is $H(Y\mid S)-H(Y\mid R)=I(Y;R\mid S)$. A fixed predictive floor $a>0$ bounds log loss by $-\ln a$ and gives the TV upper bound $(-\ln a)D_\phi$ for the constrained readouts. A rent exceeding $D_\phi$ in unit-payoff units cannot be repaid by raw access in any task in the declared class. Which policy a limited learner can find or execute remains a further constraint.

**Learning from observations.** Write $d_w(\mu,\tau)=\sum_e w_e\,\mathrm{TV}(\mu_e,\tau_e)$. For a fixed encoder the value changes by at most $d_w(\mu,\tau)+d_w(\phi_\#\mu,\phi_\#\tau)\le2d_w(\mu,\tau)$, where both pushes retain the hidden outcome. The triangle inequality applies separately to original laws and simulated laws, and every decoder contracts TV. This bound holds simultaneously over all deterministic encoders. If each of $N_e>0$ independent observations in each context is also independent across contexts, let $d_e$ be an upper bound on the support size of its labeled raw observation. The empirical objective, even if used to select the encoder, obeys with probability at least $1-\eta$
$$
\sup_\phi |D_\phi(\hat\mu)-D_\phi(\mu)|
 \le B=\sum_e w_e\sqrt{(d_e-1)/N_e}
 +\sqrt{2\ln(1/\eta)\sum_e w_e^2/N_e}.
$$
For each empirical histogram Cauchy–Schwarz and the coordinate variances give expected TV at most $\sqrt{(d_e-1)/N_e}/2$. Changing one sample changes weighted TV by at most $w_e/N_e$. The bounded-differences inequality and the preceding deterministic comparison give the result. Minimizing empirical deficiency plus a known encoding or execution charge consequently gives population objective within $2B$ of the best candidate, plus any optimization error. The certificate can be vacuous for a large observation alphabet. It does not assume independent samples along a natural text stream or estimate that stream’s information loss. ## Which causal simulator does a finite-horizon decision test?

Fix a finite controlled experiment, prior on its hidden state $\theta$, action alphabets and horizon. Let $\mathcal P,\mathcal Q$ be the convex hulls of joint laws of $\theta$ and the **actual action sequence** obtainable by the raw and coarse controllers, respectively. A coarse controller receives its observations at their declared times and obeys its specified memory restriction. Ex-ante mixtures use randomness independent of the environment. For terminal rewards $g(\theta,a_{1:T})\in[0,1]$ the largest difference of optimal returns is exactly
$$
D_{\rm act}=\max_{P\in\mathcal P}\min_{Q\in\mathcal Q}\mathrm{TV}(P,Q).
$$
Indeed the supremum over $g$ commutes with maximization over $P$. At fixed $P$, finite minimax interchanges $g$ and $Q$, and maximizing $\mathbb E_Pg-\mathbb E_Qg$ gives TV. Distance to the convex set $\mathcal Q$ is convex in $P$, so a pure raw policy suffices. This is the directed-distance criterion for attainable laws applied to a sequential experiment. It includes the effects of real actions on subsequent observations.

Suppose a causal simulator $K$ supplies a virtual raw observation to a fixed raw policy $\pi$ from the coarse observations so far, past actions and its private randomness. The action is executed in the coarse experiment. Let $E(\pi,K)$ compare the true and simulated laws of $(\theta,a_{1:T})$ in TV. If the composition of $\pi$ and $K$ is an allowed coarse policy, then
$$
D_{\rm act}\ \le\ \max_\pi\min_K E(\pi,K)\ \le\ \min_K\max_\pi E(\pi,K).
$$
The first inequality can be strict. Example: $\theta$ is a fair bit. An initial purchase reveals $\theta$ early in the raw experiment and late in both experiments. Skipping returns blanks at both dates. One final binary decision follows the late observation. Every raw law of initial and final actions can be matched directly by a coarse policy, hence $D_{\rm act}=0$. Yet consider the raw policy that purchases, remembers the early bit and reports it at the end regardless of the later bit. A causal simulator must send its early bit before learning $\theta$, giving TV at least $1/2$. A fair early coin followed by copying the true late observation gives full-path TV at most $1/2$ for every policy by coupling. Information available by the decision deadline suffices for matching its attainable rewards. A prescribed raw computation may require an earlier commitment. On a finite machine the simulator's working state, policy state and retained random seed must fit the coarse comparison budget for the first inequality to apply.

There is an equality for a different observation of the interaction. Include all virtual or raw observations $r_{1:T}$ in the trajectory tested by TV and permit private ex-ante mixtures over deterministic raw plans. For a fixed path the raw and simulated probabilities factor as $h_\pi(r,a)p(\theta,r\Vert a)$ and $h_\pi(r,a)q_K(\theta,r\Vert a)$. Here $h_\pi$ is the probability that the controller's plan prescribes the listed actions along the listed observations. The two remaining factors are the interventional path weights under the listed actions. Summing out actual coarse signals gives the second factorization, since $K$ only sees the allowed history. In their absolute difference the common nonnegative $h_\pi$ factors out. Thus full-path TV is linear in a mixture of raw plans and convex in a mixture of simulators. With finite alphabets, the closed simplices of plans and simulators are compact. Finite-dimensional convex minimax now gives
$$
\max_{\mathrm{mixed}\ \pi}\min_K E_{\rm full}(\pi,K)
=\min_K\max_{\mathrm{pure}\ \pi}E_{\rm full}(\pi,K).
$$
The controller's private choice of plan must be hidden from $K$. Projecting away $r$ moves a sum inside the absolute value and can destroy linearity. Restrictions excluding mixtures can likewise change the answer.

**Exact price of requiring a single simulator for pure controllers.** Give $\theta=1,2,3$ prior $(4,3,2)/9$. A raw early bit $X$ is zero with respective probabilities $(1/4,3/4,1/2)$. After wait, the late raw bit $B$ is $\mathbf1_{\theta=1}$. Probe gives $\mathbf1_{\theta=2}$ if $X=0$ and $\mathbf1_{\theta=1}$ otherwise. The coarse experiment supplies blanks throughout. Include the initial decision and permit reporting both $(X,B)$ in the terminal action. A shared causal simulator must fix $q=\Pr(\widetilde X=0)$ before seeing whether the controller waits or probes. It can condition the late simulated bit on both its early bit and the action.

For a branch $(x,a)$ write $s_i=\Pr(X=x\mid\theta=i)$ and $b_i=B(x,a,i)$. If the simulator puts total mass $m$ on that early word, its maximum overlap contribution is
$$
f_{xa}(m)=\max_{u_0+u_1=m,\ u_0,u_1\ge0}\sum_i\Pr(\theta=i)\min(s_i,u_{b_i}).
$$
Allocate mass successively to the reporting bit with the largest remaining slope. At $x=0$ the wait slopes and widths are $(5/9,1/2),(4/9,1/4),(3/9,1/4)$; the probe list is $(6/9,1/4),(3/9,3/4),(2/9,1/4)$. At $x=1$ both decisions have the same list $(5/9,1/4),(4/9,3/4),(2/9,1/4)$. Each list has slope zero once exhausted. The total overlap is $f_{0a}(q)+f_{1a'}(1-q)$, independent of $a'$. Its maximum is $19/36$ for either $a$, attained at $q=1/2$ for wait and $q=1/4$ for probe. Imposing the same $q$ gives maximum worst-case overlap $37/72$ at $q=3/8$. Thus the pure policy-specific deficit is $17/36$, whereas the shared deficit is $35/72$, a strict gap of $1/72$. Full terminal reporting attains these distances. Its data processings upper-bound the distance for any other terminal reports. ## Pricing a compressed learning state by its future predictions

Fix a finite horizon, a policy for choosing the next context or action from its past, and a proper conditional observation law for each latent hypothesis $z$. Parameters governing future emission updates belong to the hypothesis or its specified generative process. With a prior $\mu$ over hypotheses, denote the induced future transcript law by $P_\mu^\pi$. A cheaper learner uses a distribution $\nu$ over possibly different conditional processes, producing $Q_\nu^\pi$. Both face the same policy applied to their own observations. For data drawn from $P_\mu^\pi$, the expected cumulative excess log loss of the second learner's continually conditioned predictions is exactly
$$
\mathrm{KL}(P_\mu^\pi\Vert Q_\nu^\pi).
$$
This is the chain rule on the transcript. Action likelihoods cancel because the policy is the same conditional function on a fixed realized path. It also applies to a deterministic intervention schedule. Absolute continuity is necessary for finite loss. Pointwise closeness of the current forecasts cannot bound this quantity for arbitrary future updates, as the four-row reachable example demonstrates. [One-observation separation](OBSTRUCTIONS.md#two-reachable-partition-posteriors-can-give-every-current-forecast-the-same-value)

There are two useful upper bounds. If the latent hypothesis set and its conditional process kernels are held fixed and only the stored prior changes, then
$$
\sup_\pi\mathrm{KL}(P_\mu^\pi\Vert P_\nu^\pi)\le\mathrm{KL}(\mu\Vert\nu)
$$
for any horizon. Apply the same transcript channel to the two priors. The upper bound is attained for a policy that reveals the latent hypothesis. If the component processes themselves change, take any coupling $\Gamma$ of the two priors. Give the pair of latent hypotheses law $\Gamma$ on both sides, and generate the transcript conditionally from its respective component. The joint KL is $\sum_{z,w}\Gamma_{zw}\mathrm{KL}(P_z^\pi\Vert Q_w^\pi)$. Forgetting the latent pair can only decrease it. Taking the infimum over couplings therefore bounds observable excess, including when latent alphabets have different sizes. These are applications of data processing and joint convexity. The bound's direction matters. Conditioning a prior on a retained subset gives a finite reverse KL of minus the logarithm of the subset mass. In the forward direction, an omitted possible outcome can have zero predicted probability. For repeated noisy bits, even strictly positive one-step laws can incur an unbounded cumulative loss as the horizon grows if an identifiable true component was discarded. Predictive regret over a declared future horizon, ongoing update work and the memory required to represent the replacement are separate quantities.

## How much can an adaptive experiment expose a forgotten hypothesis?

Draw a latent row $Z$ from a fixed finite prior $\mu$ once. At time $t$ an observable policy selects $A_t$ from its preceding actions and outcomes. Given $Z=z$ and the selected action $a$, it receives a fresh Bernoulli draw of mean $p_{za}$. Compare the true mixture with a predictor that always issues $q_a$ at action $a$. Write $H_T=(A_1,Y_1,\ldots,A_T,Y_T)$, $d$ for Bernoulli KL in nats and $d_{za}=d(p_{za}\Vert q_a)$. Both transcript laws use the same policy, including any conditional randomization. Splitting the joint log likelihood through the mixture gives
$$
D_T^\pi=D(P_\mu^\pi\Vert Q_q^\pi)
=\sum_z\mu_z\sum_a E_z^\pi N_a(T)\,d_{za}-I(Z;H_T).
$$
The expected arm log likelihood conditional on the row gives the first term. The average log likelihood of a row relative to the mixture is the mutual information. The policy probabilities cancel on each possible path. The identity also holds with a stateful forecast $q(H_{t-1},a)$ inside the per-time expectation. A comparator assigning zero probability to a possible outcome already has infinite worst-policy KL at horizon one. Constant arms matching every positive-prior row have zero divergence. All other statements below use finite $d_{za}$.

**Passive observations.** Hold one action fixed and set $q=\bar p=\sum_z\mu_z p_z$. With binary entropy $h$, put $J=h(\bar p)-\sum_z\mu_z h(p_z)$. Then $D_T=TJ-I(Z;Y^T)$. The first prediction is exact. The increments $D_{t+1}-D_t$ increase weakly from zero to $J$ because conditioning reduces $H(Y_{t+1}\mid Y^t)$ and the sequence is exchangeable. The information term tends to the entropy of the *distinct* coin biases under the prior. The empirical mean identifies that finite class almost surely, so its conditional entropy vanishes. Thus $TJ-H(p_Z)\le D_T\le(T-1)J$ for $T\ge1$. A nonconstant $p_Z$ incurs loss by the second draw because $\operatorname{Cov}(Y_1,Y_2)=\operatorname{Var}(p_Z)>0$. For a binary mixture the residual uncertainty is at most $h(\sqrt{\mu_0\mu_1}\,\rho^T)$, with $\rho=\sqrt{p_0p_1}+\sqrt{(1-p_0)(1-p_1)}$. Bound the MAP error by the sum of geometric means of the two weighted path probabilities, then apply the binary error-entropy inequality. A budget $b$ is certainly exceeded once $TJ>b+H(p_Z)$. As a prior mass vanishes, $J$ tends to zero and at zero mass the merge is exact. These finite-horizon and fixed-prior limits need different quantifiers.

**Chosen observations.** With finitely many actions and the response rows available to a diagnostic controller, the worst observable price per observation is
$$
\lim_{T\to\infty}\frac1T\sup_\pi D_T^\pi
=R(q)=\sum_z\mu_z \max_a d_{za}.
$$
The upper bound follows from the identity. Merge identical row vectors. For $m$ arms and at least two distinct rows let $\delta>0$ be their minimum sup-norm separation. Pull every arm $n=\lceil 2\delta^{-2}\ln(2mT)\rceil$ times if $mn\le T$. The nearest row to the vector of empirical means is wrong with probability at most $1/T$ by Hoeffding and a union bound. Play its maximizing arm thereafter. The total difference from $TR(q)$ is at most $n\sum_{z,a}\mu_z(\max_b d_{zb}-d_{za})+\max_{z,a}d_{za}+H(Z)$. One row needs no exploration. This construction uses $m$ success counts of $O(\log n)$ bits each, a sampling schedule and the known prototypes. When a policy must preselect the entire action sequence independently of outcomes, its optimal limiting rate is $\max_a\sum_z\mu_z d_{za}$.

The logarithmic exploration cost can be necessary. Take three equally likely rows $(.5,.5),(.5,.9),(.8,.1)$ and $q=(.6,.5)$, the armwise prior means. Put $g=d(.5\Vert .6)>0$. The first row prefers arm one with gap $g$ and the second prefers arm two with gap $d(.9\Vert .5)-g>0$. Any sequence of optimal finite-horizon policies has total deficiency $O(\log T)$ by the preceding construction, hence $E_1 N_2$ and $E_2(T-N_2)$ are both $O(\log T)$. For $E=\{N_2\le T/2\}$ this gives $P_1(E)=1-O(\log T/T)$ and $P_2(E)=O(\log T/T)$. The two rows agree on arm one. Their transcript KL is $d(.5\Vert .9) E_1N_2$, at least $P_1(E)\ln(1/P_2(E))-\ln2$ by data processing. Thus the deficiency is at least $(g/[3d(.5\Vert .9)]-o(1))\log T$. The change-of-measure step is the deterministic-horizon case of Kaufmann, Cappé and Garivier, Lemma 1 and Appendix A.1. The FP comparison prices the observable predictions lost by a compression. **Best memoryless replacement.** Let $\tau(a\mid z)$ select an arm from a latent row for purposes of the variational formula. Give $(Z,A,Y)$ law $\mu_z\tau(a\mid z)\operatorname{Bern}(p_{za})$. Then

\inf_q R(q)=\max_\tau I_\tau(Z;Y\mid A).
$$
For fixed $\tau$ the weighted average divergence equals $I_\tau(Z;Y\mid A)+\sum_a P_\tau(a)d(E_\tau[Y\mid a]\Vert q_a)$. This follows by inserting the conditional mean into the log ratio separately for each arm with positive mass. Clipping each conditional mean increases average divergence by at most $-\ln(1-\epsilon)$, uniformly in $\tau$. Taking $\epsilon\downarrow0$ covers endpoints and unused arms. ## What is a hidden distinction worth under a different observation interface?

Consider the two known clock-period hypotheses $k$ and $k+1$, $k\ge3$. At age $j$ the red probability is $h_k(j)=(1+c\cos(2\pi j/k))/2$ for fixed $0<c<1$. The learner sees ordinary color outcomes. A destructive read resets the age; a nondestructive read leaves it available for reuse. All advances and reads are paid. **Proved.** Write $L=\ln(1/\delta)$ for $0<\delta\le1/8$. The optimal work to distinguish the two hypotheses with both error probabilities at most $\delta$ has the following orders.

| Available observations | Work |
|---|---:|
| One passive stationary token stream | $\Theta_{t,c}(k^6 L)$ raw tokens |
| Deliberate ticks and destructive color reads | $\Theta_c(k^2 L)$ operations |
| Deliberate ticks and nondestructive color reads | $\Theta_c(k^{4/3} L^{1/3}+L)$ operations |

The distinctions come from the cost of reaching and reusing an informative age. Let $K=k(k+1)$, $a=\pi(2k+1)/K$ and $b=\pi/K$. The red-probability difference is $d_j=-c\sin(aj)\sin(bj)$. It satisfies $|d_j|\le C_c\min(1,j/k^2,j^2/k^3)$. For the two possible Bernoulli color laws write $I_j=-\ln(\sqrt{p_j q_j}+\sqrt{(1-p_j)(1-q_j)})$. Both this quantity and each directed KL are bounded above and below by constants times $d_j^2$, since all color probabilities lie in $[(1-c)/2,(1+c)/2]$.

**Paying for a read that resets.** After paying $j+1$ for one color at age $j$, the next probe must start again. Its KL is at most $C_c\min(1,j^2/k^4)\le C_c(j+1)/k^2$. The adaptive KL chain rule gives the same bound per unit of total work. A test with the requested errors needs at least a constant times $L$ KL by binary data processing. Conversely $j_*=k\lfloor(k+1)/2\rfloor$ has cosine one at period $k$ and cosine close to minus one at period $k+1$. Its color means differ by a constant depending only on $c$. Repeating this probe $O_c(L)$ times attains the bound.

**Paying for a read that preserves its subject.** With work budget $T$, all ages queried are at most $T$. The adaptive KL is at most $C_c\min(T,T^3/k^4)$. For achievability in the intermediate range $Ck\le T\le K/2$, there is a $j$ in $[T/4,T/2]$ with $|\sin(aj)|$ bounded below by an absolute constant. Indeed cosine partial sums at frequency $2a$ are bounded by $1/|\sin a|=O(k)$, so the mean of $\sin^2(aj)$ on that interval is bounded below for large enough $C$. On it $|\sin(bj)|\gtrsim T/k^2$. Advance to this age and take the remaining $T-j$ independent reads there. Their total negative log affinity is at least a constant times $T^3/k^4$. For $T\ge2(j_*+1)$, reading repeatedly at $j_*$ gives order $T$ instead. Monotonicity covers the constant-factor gap between the two ranges. Product affinity bounds the sum of errors of the likelihood-ratio test. Inverting the bound yields the stated two-term rate, including its transition at $L$ of order $k^2$. These adaptive lower bounds also apply to expected cost with the same orders. If expected work under either true hypothesis is at most $B$, truncate at $8B$. The event of having stopped and chosen the correct first hypothesis has probability at least $1-\delta-1/8$ under that hypothesis and at most $\delta$ under the other. Apply the fixed-budget KL argument to the truncated experiment.

**An exact cost comparison for a fixed budget.** The smallest attainable transcript affinity with either active interface is the exponential of minus its greatest attainable sum of $I_j$ values. In the destructive case this exponent obeys $V(0)=0$ and
\[
 V(T)=\max\{0,\max_{0\le j<T}[I_j+V(T-j-1)]\}.
\]
In the nondestructive case it equals $\max_{0\le j<T}(T-j)I_j$. To prove the claim, condition on the first read of a policy tree. Its two child subtrees start at the same age and with the same remaining resources. Each optimized continuation affinity is independent of the previous color, and the two square-root weights sum to the one-read affinity. Backward induction therefore permits an optimal fixed schedule for this objective. In a nondestructive schedule, paying to reach at least the most informative age used and concentrating all reads at that age is optimal. This argument concerns the affinity objective; the testing-rate lower bound separately covers every adaptive decision policy.

**The deployment task changes the value of the learned distinction.** Let the prior on the two periods be fair and let the observed training transcript leave posterior probability $q$ on the first hypothesis. On one new color prediction at a supplied age drawn independently from $\nu$, the Bayes excess expected log loss relative to knowing the period is
\[

\]
Here $h$ denotes binary entropy and $p_j,p'_j$ the two red probabilities. Since $-h''$ is bounded above and below on the allowed probability interval, this excess lies between constant multiples of $q(1-q)\Lambda_\nu$, where $\Lambda_\nu=\mathbb E_\nu d_j^2$. ## How many bits must control the mixture of two changing predictors?

At a pruning cut, suppose the retained predictor and a cheaper fallback have initial weights $1-\eta,\eta$. Both can continue to learn from the same ordinary observations. The ideal sequence law is the fixed-prior mixture of their two full causal laws. Its posterior weights may require increasing precision even when each component has bounded memory.

**PROVED, deterministic finite weights.** With $s$ persistent bits let $H=2^s$. Encode $H$ possible weights $v_j=j/(H+1)$ for $j=1,\ldots,H$. At the cut and after each Bayes update of the *current finite-precision* predictor, map a desired weight $z$ to $v_{\min(H,1+\lfloor Hz\rfloor)}$. Both resulting weights are at least $\lambda=H/(H+1)$ times their desired values. Multiply each component's currently allocated probability mass by its own next-token forecast before performing the new rounding. Induction shows that after $N$ forecasts the reported prefix probability is at least $\lambda^N$ times the ideal mixture probability, for **every raw tape and every pair of causal predictors**. Counting the initial rounding makes the bound valid at the first token. It costs at most $N\ln(1+2^{-s})$ nats. The exact reference posterior and the tape likelihood used to audit it require no space in the deployed gate.

This local precision guarantee is sharp. One reported weight $v$ can dominate both coordinates by factor $\lambda$ only on $z\in[(v+\lambda-1)/\lambda,v/\lambda]$. Covering $[0,1]$ with $H$ such intervals requires $\lambda\le H/(H+1)$, achieved by these evenly spaced weights. For this reporting rule the cumulative bound itself is attained with a pure initial expert, deterministic opposite forecasts, and repeated observations of that expert's output. Strictly positive laws approximate equality on a fixed horizon. The local proof concerns a guarantee for all component weights and tapes.

With $m$ active predictors, let $l=m-1$. One representative covers a subset of a translated reflected simplex of relative volume $[(1-\lambda)/\lambda]^l$, hence $\ln(1/\lambda)\ge\ln(1+H^{-1/l})$ for any $H$-point componentwise cover. For an upper bound choose all strictly positive $m$-part integer compositions of $K+l$, normalized by that denominator. Round each coordinate to $\max(1,\lceil Kz_i\rceil)$ and distribute leftover units in a fixed order. Their sum never exceeds $K+l$, since the total upward rounding is an integer strictly below $m$. This uses $\binom{K+l-1}{l}$ representatives and $\lambda=K/(K+l)$. The deterministic local cost therefore scales as $\Theta_m(2^{-s/(m-1)})$ with $s$ stored bits at fixed $m$. Its conditional output and update law given its state, token and fresh randomness is fixed within that run. The bound therefore also gives a fixed tape with at least that expected loss over the learner's private draws. Ratios of their positive entries are in $[1/\ell,\ell]$, since each entry mixes the same two token-conditioned update probabilities. This holds if the predictor uses common local randomness for its report and its update, because the iid symbol is independent of that randomness. Set $\epsilon=2/N$. For either model, mix its transition with probability $\epsilon$ of returning to the common initial distribution. For $0<\epsilon<1$ the reset chain is irreducible on the common reachable set. Its stationary distribution is the discounted occupancy $\epsilon\sum_{t\ge0}(1-\epsilon)^t\mu_0 T_\pm^t$. The ratios of corresponding positive entries in the reset matrices obey the same bounds. By the finite Markov-chain tree formula, unnormalized rooted tree sums under the two chains differ by at most $\ell^{H-1}$ in either direction. Normalizing divides by a further sum with the same multiplicative bounds. Hence corresponding stationary masses differ by at most $\ell^{2(H-1)}<e<3$. Indeed $\ln\ell\le2/(4H-1)$. For $\epsilon=1$ the discounted distributions coincide directly.

A binary decision from these discounted states under equal priors has average error at least $1/(1+\ell^{2(H-1)})>1/4$. This follows by summing the coordinatewise overlap, and includes randomized readouts. Threshold the learner's issued probability at $1/2$ and let $e_t$ denote its equal-prior error at prediction time $t$. Its discounted error is at least $1/4$ by time homogeneity. The tail at $t\ge N$ has weight at most $e^{-2}$ and each earlier weight is at most $2/N$. Thus $N^{-1}\sum_{t<N}e_t\ge(1/4-e^{-2})/2>1/20$. On a wrong decision the reported probability differs from the true bias by at least $a$, incurring expected extra log loss of at least $2a^2$ by Pinsker. The independent source with its identity supplied is a stronger oracle than the ideal mixture. Averaged over source identity and outcomes, the latter's extra loss above that oracle is at most $\ln2$ by mixture domination. Combining the inequalities proves the claim.

## The cost of learning the last observable coordinate

Use the preserving clock, $k=2m\ge4$, and two populations of fresh initial phases $w_\pm(j)=[1\pm\tau(-1)^j]/k$, $0<\tau\le1$. A panel means one independently drawn initial phase followed by ordinary raw outcomes from that phase and its subsequent ticks. A fresh panel is a separate acquisition operation. A mark that resets a clock to the known phase zero cannot supply a fresh population draw. The two populations differ only in their parity Fourier coefficient. Fewer than $m$ marks in any fresh panel yield identical laws, even when every observed tick count is retained. Exactly $m$ marks suffice for identifiability. The statistical price of using just that many differs sharply from the price when longer observations are allowed. [Moment rank and observation model](FOUNDATION.md#which-coordinates-of-a-phase-distribution-can-ordinary-future-words-see)

**PROVED, fixed mark cap.** For fixed contrast $c\in(0,1)$ and large $m$, distinguishing the populations with both errors at most $\delta\le1/8$ from independent passive panels stopped at mark $m$ requires and suffices to use
\[
 \tau^{-2}\ln(1/\delta)
 \left[\frac{2}{1-\sqrt{1-c^2}}\right]^m\exp(o_c(m))
\]
panels. At $c=1/2$ the exponential base is $8+4\sqrt3$, about 14.93. Each such panel consumes $2m$ raw tokens on average.

Here is the information calculation. Let $\theta=\pi/m$, let $n_l$ be the cumulative number of ticks before mark $l$, and let $\sigma_l$ be its sign. Use as reference the ordinary geometric tick waits and independent fair signs. The density for phase $j$ relative to this reference is $F_j=\prod_{l=1}^m[1+c\sigma_l\cos(\theta(j+n_l))]$. Write $\bar F$ for the phase average. Under a uniform phase, the conditional parity mean is
\[
 f=\frac{2(c/2)^m(\prod_l\sigma_l)\cos\psi}{\bar F},\qquad
 \psi=\theta\sum_l n_l.
\]
Only the highest positive and negative frequencies survive the signed phase sum, and both alias to parity at $k=2m$. The two population densities relative to the uniform-phase law are $1\pm\tau f$. Consequently
\[
 I_m=\mathbb E_0 f^2=4(c/2)^{2m}\mathbb E_{\rm ref}[\cos^2\psi/\bar F].
\]
The affinity deficit is between $\tau^2 I_m/2$ and $\tau^2 I_m$ by $1-\sqrt{1-u^2}$. Both directional KLs are $O_c(\tau^2 I_m)$ for large $m$ by the uniform bound on $|f|$ below. Binary decision data processing gives the stated sample lower bound in terms of $1/(\tau^2 I_m)$, and the likelihood test and product affinity give the upper bound.

Put $B=(1+\sqrt{1-c^2})/2$ and $\rho=c/(1+\sqrt{1-c^2})<1$. Since $1+c\cos x=B|1+\rho e^{ix}|^2$, taking the geometric mean over all $2m$ phases in each factor yields $\bar F\ge B^m(1-\rho^{2m})$ for every realized word. The shifts and sign changes permute these roots of unity. In particular $|f|\le2\rho^m/(1-\rho^{2m})$. The same upper bound on $I_m$ applies if a policy chooses tick advances using past signs and reads at most $m$ times. On each completed sign path its chosen shifts are fixed and the common policy factors cancel.

For the reverse exponential bound under the passive clock, the reference waits are independent with mean one and variance two. The maximal inequality for their centered sums gives $\max_{l\le m}|n_l-l|\le m^{3/4}$ with probability tending to one. Conditional on such waits, $\mathbb E_\sigma\ln F_j=\sum_l\tfrac12\ln(1-c^2\cos^2(\theta(j+n_l)))$. Replacing $n_l$ by $l$ costs $O_c(m^{3/4})$ uniformly in $j$, by the bounded derivative. The resulting smooth periodic sum samples a whole period and equals $m\ln B+O_c(1)$ by the factorization above and its circle average. Hoeffding's inequality and a union bound over $2m$ phases give $\bar F\le B^m\exp(o_c(m))$ with reference probability tending to one. Moreover $\mathbb E e^{2i\psi}=\prod_{q=1}^m(2-e^{2\pi iq/m})^{-1}=1/(2^m-1)$, so $\mathbb E\cos^2\psi\to1/2$, also after omitting the exceptional event. Thus $I_m=[(1-\sqrt{1-c^2})/2]^m\exp(o_c(m))$. The asymptotic exponent concerns the experiment stopped at its first informative mark count, with fixed contrast.

**PROVED, longer observations change the optimal total price.** With the same hypotheses and independently restartable panels, if their lengths are selectable, the necessary and sufficient expected number of passive raw tokens is
\[
 \Theta_c\!\left(k^2\tau^{-2}\ln(1/\delta)\right).
\]
The same lower order applies to the number of informative color reads even if known rotations are free.

For the lower bound, give the learner the containing pair $\{2j,2j+1\}$ on every fresh draw. Its pair label is uniform under both population hypotheses. Conditional on a common observed panel, let $u$ be the likelihood ratio of its tape under the even start versus its adjacent odd start. Their posterior even weights under the two population hypotheses differ by $4\tau u/[4u+(1-\tau^2)(u-1)^2]\le\tau$. Adjacent starts remain adjacent after every tick. Their next red probabilities conditional on a mark differ by at most $c\sin(\pi/k)$, so the two population forecasts differ by at most $\tau c\sin(\pi/k)$. All color probabilities lie in $[(1-c)/2,(1+c)/2]$. Each color read supplies conditional KL at most $4\tau^2c^2\sin^2(\pi/k)/(1-c^2)$. Tick times carry no population information. Conditional on the supplied pair labels and the global hypothesis, separate panels have independent phases, so adaptive stopping and choice among open panels preserve this bound by the chain rule. Truncation gives the same result for expected cost. Achieving the stated testing risk requires order $\ln(1/\delta)$ KL, even with the extra pair information.

For the upper bound, within one panel observe a multiple $T$ of $k$ tick intervals. At each offset $q=0,\ldots,T-1$ use the first raw symbol after the preceding tick, including the initial position at offset zero. Give this symbol value $Y_q=+1,-1,0$ for red, blue, tick. Conditional on the starting phase, these disjoint intervals are independent, with $\mathbb E[Y_q\mid J]=(c/2)\cos(\theta(J+q))$. The complex statistic $4\sum_qY_q e^{-i\theta q}/(cT)$ is unbiased for $e^{i\theta J}$ by discrete orthogonality. Its real and imaginary parts concentrate at scale $1/\sqrt T$. With $T=C_c k^2$ rounded to a multiple of $k$, nearest-phase decoding errs with probability below $1/10$ uniformly in $J$. Issue a parity score of zero on ties. Complete turns and cyclic symmetry give opposite signed mean parity scores under the two hypotheses, separated by at least $2\tau(1-2/10)$. Using $O(\tau^{-2}\ln(1/\delta))$ independent panels and thresholding their mean suffices. Passively waiting for the $T$ ticks costs $2T$ raw tokens on average. With a fixed hard cap a constant-factor allowance and a negative-binomial tail bound suffice at the same order. With a single unrestarted trajectory, learning its initial phase can furnish only one draw from the population. ## The cost of detecting a weak distinction when restarting has a price

**PROVED for binary observations.** The two-state source emits $X_i=S_iE_i$, where the starting sign $S_1$ is fair, $S_{i+1}=S_iJ_i$, and the independent signs $J_i,E_i$ have means $a,\rho$ respectively, with $0<|a|,\rho\le1$. A fresh subject starts fair. An ordinary observation costs one unit. After a cut, voluntarily obtaining a fresh subject costs $c\ge0$, with the first subject free. Hidden states advance only on observed steps. The alternative parameters are supplied and the type-I and type-II errors must each be at most $0<\delta\le1/4$. Against a *known fair iid law*, the optimal observation count on one continuing subject is $\Theta(A\ln(1/\delta))$, where
\[
 A=\rho^{-2}+\frac{1-a^2}{a^2\rho^4}.
\]
Against *all iid Bernoulli laws* with one common unknown bias across subjects, the optimal hard total cost, including adaptive schedules, is
\[
 \Theta\!\left(\left[A+\mathbf1_{\{a>0\}}\min\{(1-a)^{-1},c\}\right]\ln(1/\delta)\right).
\]
For $a=1$ take $(1-a)^{-1}=\infty$. With restarts unavailable, the term is $(1-a)^{-1}$ for $0<a<1$. At $a=1$ on one subject the alternative is a mixture of two iid null laws, so the uniform test is impossible. At $a=0$ or $\rho=0$ the alternative is itself fair iid. Positive and negative persistence have different costs against an unknown pooled bias even at the same magnitude.

**Lower bounds.** Let $m$ be the predicted mean of the hidden sign. Observing an outcome $x$ yields mean $(m+\rho x)/(1+\rho mx)$. Its conditional expected square is $m^2+\rho^2(1-m^2)^2/(1-\rho^2m^2)\le m^2+\rho^2$, with endpoints understood by continuity on feasible observations. The subsequent hold multiplies the mean by $a$. The conditional KL of this observation from a fair coin is at most $(\ln2)\rho^2m^2$, by the even power series of binary relative entropy. Summing the potential $m^2$ bounds the sum of predictive squares by both $N$ and $N a^2\rho^2/(1-a^2)$ in expectation. The same telescoping works under a budget or a stopping time by summing the potentials of all retained subjects. A fresh subject has zero potential. The chain rule and binary testing data processing give the lower order $A\ln(1/\delta)$ even with free restarts.

For positive $a$, mix the two iid nulls with means $\pm\rho$ in equal proportions, choosing one bias for the entire experiment. Conditional on any realized schedule, transcript and private policy randomness, paths on which every natural transition preserves that chosen sign and every voluntary restart redraws it contribute at least $[(1+a)/2]^n 2^{-R}$ times the null-mixture transcript likelihood. Here $n$ is its number of reads and $R$ its paid restarts. This is a pathwise likelihood bound for a policy acting on its observed past. For $n+cR\le B$, the factor is at least $\exp[-B\max\{-\ln((1+a)/2),(\ln2)/c\}]$. Apply it to the decision to accept iid. Its null probability is at least $1-\delta$ and alternative probability at most $\delta$. This proves the additional lower order $\min\{(1-a)^{-1},c\}\ln(1/\delta)$, interpreted as zero when resets are free.

**Achievability and storage.** Set $r=|a|$, $b=\max(2,\lfloor\min\{(1-r)^{-1},\rho^{-2}\}\rfloor)$ and $\mu=\rho^2\sum_{l=1}^{b-1}(b-l)r^l\asymp\rho^2rb^2$. The last comparison follows from the first lag for $b=2$ and from $b(1-r)\le1$ for larger blocks. Against the fair null, change alternate signs if $a<0$ and take the sum $S$ of $b$ successive resulting signs. Then $U=(S^2-b)/2$ has mean zero under the null and $\mu$ under the split. In disjoint blocks $U$ is independent under both laws because the starting sign cancels from the square, leaving disjoint transition and emission innovations. Under the split, conditional on the hidden path, independent emissions have aggregate mean at most $b\rho$ in magnitude and fourth centered moment $O(b^2)$. Since $b\rho^2\le2$, the second moment of $U$ is $O(b^2)$ under both laws. Averaging $L=O(1+b^2/\mu^2)$ blocks therefore gives a constant-error test, by thresholding at $\mu/2$ and choosing the constant using Chebyshev. A majority of $O(\ln(1/\delta))$ independent batches suffices. The cost per batch $bL$ is $O(A)$, checking separately $b=2$, $b\asymp(1-r)^{-1}$ and $b\asymp\rho^{-2}$.

For an unknown iid bias and $a>0$, two independent length-$b$ subjects with sums $S,S'$ give $U'=(S-S')^2/2+SS'/b-b$. Its mean vanishes for every iid bias. Its alternative mean is $2\mu$. The second moment stays $O(b^2)$ because the iid difference is centered, the split difference has conditional mean at most $2b\rho$, and $|SS'|/b\le b$. On a single subject take two blocks whose starting positions are $T=2b+g$ apart, with $g=\lceil\ln(32)/[-\ln(a)]\rceil$. The alternative mean is reduced by $(1-1/b)\rho^2\sum_{i,j=1}^b a^{T+j-i}\le b^2\rho^2 a^{b+g+1}$, leaving a constant fraction of $\mu$. All intervening reads are charged. The two-block statistic still cancels the common starting sign, giving independence across disjoint segments. If $c<(1-a)^{-1}$, fresh subjects cost $O((b+c)L)$ per batch. If $c$ is large compared with $b$ in this regime, $b\asymp\rho^{-2}$, $a$ is bounded away from zero, and $L=O(1)$. Otherwise use the single-subject design, costing $O((b+g)L)=O(A+(1-a)^{-1})$ by the same cases. At $a=1$ the fresh-subject design applies. For negative $a$, use disjoint paired differences $Y_j=X_{2j}-X_{2j-1}$. They are independent and centered under every iid bias. Under the split their lag-$l$ product has mean $\rho^2r^{2l-1}(1+r)^2$. Summing pair products within blocks of $b$ differences gives the same order $\rho^2rb^2$ and the same second-moment and independence bounds, at twice the raw length. Thus no resets are needed there.

With supplied parameters, the block tests use signed sums, integer scores (multiply $U'$ by $2b$), a count of squared paired differences where needed and a majority counter. Persistent data memory is $O(\log(2+b)+\log(2+L)+\log(2+g)+\log(2+\ln(1/\delta)))$ bits including the charged gap clock when used. Thresholds can be stored as rounded integers at the scale of a batch. Computing or storing the supplied parameter descriptions has its own cost. This is detection of a specified weak distinction against a class of pooled models. Estimating both unknown emissions and unknown transitions is a different statistical requirement. ### The price of distinguishing exact normalization from a linear state

For $|a_y|\le r<1$, $|d_t(y)|\le1$ and $M=r\epsilon/(1-r)\le1/2$, both the exact and linear signed states of the lexical split stay in $[-M,M]$ on every history. Indeed the absolute posterior spin under the exact update is at most $|m|+|\epsilon d|$. For opposite signs it is bounded by their larger magnitude. For equal signs its denominator is at least one. Clipping in the linear update is unnecessary in this regime. The one-step discrepancy beyond multiplying the previous state difference by $a_y$ is bounded by $r\,|m+\epsilon d|\,|\epsilon m d|/|1+\epsilon m d|$. Summing this contraction shows the two signed states differ by $O(r^2\epsilon^3/(1-r)^3)$. Their predictive laws consequently differ pointwise by at most $B_t(y)O(r^2\epsilon^4/(1-r)^3)$. Both laws dominate $B_t/2$ when $0\le\epsilon\le1$, giving conditional KL at most $O(r^4\epsilon^8/(1-r)^6)$ uniformly over histories. A weak state may therefore be visible considerably earlier than the particular nonlinear operation used to update it.

**Sharp independent three-token comparison.** For the fair binary alternative above, let $x=(x_1,x_2,x_3)\in\{-1,1\}^3$ and $0<\rho\le1/4$. Direct multiplication gives, at the same parameters,
\[
 P_{\rm linear}(x)-P_{\rm exact}(x)
 =\tfrac18a^2\rho^4(a x_2+x_1)x_3 .
\]
All cells have a common positive lower bound here. Their KL is $O(a^4\rho^8)$, while the difference in means of $x_1x_3$ is exactly $a^2\rho^4$. Testing data processing gives the lower bound and averaging that sign product gives the upper bound. The sharp panel count for both errors at most $\delta$ is $\Theta(|a|^{-4}\rho^{-8}\ln(1/\delta))$.

Allow the *competing linear filter* to fit both its own common hold $\alpha\in[-1,1]$ and emission contrast $0\le\eta\le1$. With $A_1=a\rho^2$, the three pair moments of the supplied exact model, ordered by positions $(12,23,13)$, are $(A_1,A_1,aA_1)$. Write $C=\alpha\eta^2$. In the linear model the first pair moment is always $C$. If $C$ is near $A_1$, clipping is inactive before the third observation since $|\alpha|\eta(1+|\alpha|)\le2\sqrt{|C|}$. The other two moments are then $C+\alpha C^2,\ \alpha C+C^2$. Choosing $C=A_1$, $\alpha=a(1-\rho^2)$ and $\eta^2=\rho^2/(1-\rho^2)$ exactly matches moments 12 and 13. Only moment 23 differs, by $\alpha C^2$. Sign symmetry makes the three pair moments determine the entire triple law. This constructs a competitor at TV distance $O(|a|^3\rho^4)$.

Conversely suppose all moment errors are less than $\kappa |a|^3\rho^4$ for a small absolute $\kappa$. The first ensures $|C|\asymp |A_1|$ and no clipping. As $C^2=O(\rho^2|aA_1|)$ with leading factor near one, the third then forces $|\alpha C|\ge |aA_1|/2$ and $|\alpha|\ge c_0|a|$. But the difference between the first two linear pair moments is $|\alpha|C^2\ge c_1|a|^3\rho^4$, contradicting their individual closeness to $A_1$. Thus some bounded moment differs at that order for every fitted linear competitor. Estimating all three moments, and using the constructed close competitor for the converse, gives **$\Theta(|a|^{-6}\rho^{-8}\ln(1/\delta))$** independent triples. Optimizing the comparison model costs an additional factor of $|a|^{-2}$ as persistence weakens. These panel counts concern triples from genuine independent starts. ## Finding an unknown raw-word distinction before it can be stored

**PROVED for the balanced $D$-word pair source.** Compare uniform independent pairs with $P_s(x,y)=(1+\kappa s_xs_y)/D^2$ for an unknown balanced $s$, $D\ge4$ and $0<\kappa\le1/2$. Detecting the split with both errors at most $\delta\le1/4$ takes $\Theta((D+\ln(1/\delta))/\kappa^2)$ independent pairs. At fixed confidence, just count equal names. Their probability changes from $1/D$ to $(1+\kappa)/D$. The binomial variance is $O(1/D)$, so $O(D/\kappa^2)$ pairs suffice with $O(\log D+\log n)$ bits for the first name, count and clock. At high confidence enumerate balanced candidates $t$ and maximize $\sum_{i=1}^n t_{X_i}t_{Y_i}$. Under the null its mean is zero for each $t$, while under $s$ its mean per pair is $\kappa (s^\top t/D)^2$. Hoeffding and a union bound over at most $2^D$ candidates give the upper rate. Uniform accuracy of all these scores to a small fixed fraction of $\kappa$ also makes the maximizing dictionary arbitrarily highly correlated with the truth up to global flip. It therefore earns a constant fraction of the oracle gain on a fresh pair. The exhaustive method can use an unordered count table and enumerate $\binom{D}{D/2}/2$ assignments. Its time cost is exponential. The polynomial spectral and swap method measured below has a separate empirical status.

For the converse put a uniform prior on the balanced signs. If $s,t$ are independent draws and $R=s^\top t/D$, the mixture likelihood relative to uniform on $n$ pairs has second moment $\mathbb E(1+\kappa^2 R^2)^n$, obtained by expanding both likelihoods and averaging each raw pair. Conditional on either assignment, $R$ is $2/D$ times the sum in a size-$D/2$ sample without replacement of the balanced signs of the other. Hoeffding's without-replacement bound gives $\Pr(|R|\ge u)\le2e^{-Du^2/4}$. Integrating the tail bounds the second moment arbitrarily close to one for $n\le cD/\kappa^2$ with small absolute $c$. Testing is then impossible at error $1/4$ by total variation. Even for known $s$ a pair supplies only $O(\kappa^2)$ KL, giving the separate $\ln(1/\delta)/\kappa^2$ lower order.

**How early can the data improve ordinary prediction?** Let $G_n$ be the optimal balanced-prior expected gain over uniform on one fresh pair after $n$ training pairs and unlimited memory. Then for $1\le n\le cD/\kappa^2$,
\[
 G_n-G_0=\Theta(n\kappa^4/D^2).
\]
For the upper bound use $Q_0$, the zero-training equality predictor, as the independent reference on each pair. Write $U_s=ss^\top-M_0$ with $M_0=\mathbb E ss^\top$. The second moment of the $k$-pair mixture relative to $Q_0^k$ is exactly
\[
 \mathbb E\big[1+\alpha(R^2-1/(D-1))\big]^k,\qquad
 \alpha=\kappa^2/[1-\kappa/(D-1)] .
\]
Indeed the diagonals of $U_s$ vanish and $\langle U_s,U_t\rangle=D^2[R^2-1/(D-1)]$. The bracketed increment has mean zero. Integrating the subgaussian overlap tail gives $\mathbb E|R^2-\mathbb E R^2|^j\le j!(C/D)^j$ for integer $j\ge2$. Expanding its exponential moment then bounds the log second moment by $C k^2\kappa^4/D^2$ if $k\kappa^2\le c'D$. By the chain rule the corresponding KL is $\sum_{i<k}(G_i-G_0)$, whose summands are nondecreasing by conditional entropy. Use $k=2n$ and bound KL by log second moment.

For the lower bound form the centered ordered count matrix $T=\sum_{i\le n}(e_{X_i}e_{Y_i}^\top-Q_0)$, interpreting $Q_0$ as its matrix of joint probabilities. Its conditional mean is $n\kappa U_s/D^2$ and $\mathbb E\|T\|_F^2\le n+n^2\kappa^2/D^2$. Since $\|U_s\|_F^2=D^2(1-1/(D-1))$, the mean inner product of $T$ and $U_s$ is of order $n\kappa$. The projection identity $\mathbb E\langle T,U_s\rangle=\mathbb E\langle T,\mathbb E[U_s\mid{\rm data}]\rangle$ and Cauchy–Schwarz lower-bound the squared norm of the posterior mean in expectation by $c n\kappa^2/(1+n\kappa^2/D^2)$. KL curvature gives the required predictive gain. In particular, for small constant $c$ the gain throughout this regime is still only $O(\kappa^2/D)$ over uniform. With a sufficiently large constant multiple of $D/\kappa^2$ samples the explicit full search earns order $\kappa^2$. The proofs do not assign an exact critical constant. Storing $b$ bits further bounds the incremental gain above equality by $O(\kappa^2\min(b^2,n\kappa^2)/D^2)$ in the small-sample regime.

**Exact recovery costs more.** For two assignments differing at $h$ names after the better global flip, let $u=1-2h/D$. Their one-pair Hellinger affinity is $1-(1-\sqrt{1-\kappa^2})(1-u^2)/2$ and their KL is $\kappa\ln[(1+\kappa)/(1-\kappa)](1-u^2)/2$. Both identities follow by counting pairs where their two sign products differ. The likelihood union bound with at most $2\binom Dh$ competitors gives exact identification from $O(D[\ln D+\ln(1/\delta)]/\kappa^2)$ pairs. For a converse, swap one fixed positive name with one of $D/2$ possible negatives. These candidates are pairwise at Hamming distance two, and one pair gives $O(\kappa^2/D)$ KL between them. Fano's inequality yields the $\ln D$ term for large $D$, and testing a single pair yields the confidence term including the small dimensions. This is a fixed-count ordered multigraph sampling model with repeats and self-loops. The classical sparse stochastic block model has established detection and reconstruction theory for a different observation law. ## When can a single retained bit start earning its mature predictive value?

**PROVED.** Continue with balanced dictionary signs on $D\ge4$ names. Count gain above the zero-training equality predictor on a fresh subject. At any sample size $n$ put $m_n=\mathbb E[u\mid{\rm training}]$ on the unordered off-diagonal edges. Its distribution is invariant under renaming and it lies in $\ker B$. Its covariance therefore has the form $\lambda_n P$ by the same three-edge-relation argument as for the original signs. For a message $Z$ with at most $H$ values, the covariance of $\mathbb E[m_n\mid Z]$ has rank at most $H-1$ and is dominated by $\lambda_n P$. Thus the **fraction of posterior variance** retained is at most $\min(1,(H-1)/R)$, $R=D(D-3)/2$. Up to absolute constants this also bounds its fraction of the additional fresh-pair log gain, by the two-sided curvature inequality. In particular, with one retained bit and $1\le n\le cD/\kappa^2$, the optimal gain has order $n\kappa^4/D^4$.

Here is a matching one-bit construction for that early regime, uniform over the actual sign assignment. Count occurrences of one fixed unordered edge in $n$ training pairs. Its reference probability is $w=2[1-\kappa/(D-1)]/D^2$. Its actual probability $q$ differs from $w$ in either direction by order $w\kappa$. Store the bit $B=\mathbf1_{\{K\ge\lfloor nw\rfloor+1\}}$ and let $\pi$ be the probability of this event under the reference. When $nw<1$, the formula $1-(1-q)^n$ gives $|\mathbb E_q B-\pi|\asymp nw\kappa$ and $\mathbb E_q(B-\pi)^2=O(nw)$. For $nw\ge1$, $nw\kappa^2=O(1)$ here. The derivative of the binomial upper-tail probability at $\theta$ is $n\Pr[\operatorname{Bin}(n-1,\theta)=\lfloor nw\rfloor]$. For $\theta$ between $w$ and $q$, $n\theta\asymp nw$ and the specified integer is within a bounded number of standard deviations. Stirling's bounds give derivative $\asymp\sqrt{n/w}$, hence $|\mathbb E_q B-\pi|\asymp\kappa\sqrt{nw}$. In both regimes the sign is that of $q-w$.

Forecast the fresh edge bin with probability $w[1+\gamma(B-\pi)]$ and leave reference conditionals within that bin and its complement. The mean linear log gain is $\gamma(q-w)(\mathbb E_q B-\pi)/(1-w)$ and the quadratic cost is at most $Cw\gamma^2\mathbb E_q(B-\pi)^2$. Choose $\gamma=c_0\kappa^2$ in the sparse regime and $c_0\kappa^2\sqrt{nw}$ in the other, with a small universal $c_0$. The gain is at least $c n w^2\kappa^4$ for every assignment. Row normalization preserves the bound on the actual second-word score. Counting and the clock require $O(\log(2+n))$ bits during training. Only the threshold bit persists, in addition to the supplied test design and calibration.

With $n\ge CD/\kappa^2$, learning a sufficiently accurate global assignment and then storing *one* fixed relative sign gives order $\kappa^2/D^2$ above the same reference. The uniform concentration bound for exhaustive likelihood fitting makes the expected fraction of misaligned names arbitrarily small by increasing $C$. Randomly breaking likelihood ties preserves name-permutation symmetry. Each of the two sign classes then has the same per-name error within class after global alignment, at most twice the overall mean. A fixed pair's estimated sign product is consequently wrong with arbitrarily small probability. Plug its estimated relative sign into the two-name coarsened predictor. A correct bit earns at least $c_1\kappa^2/D^2$, and an erroneous bit costs at most $C_1\kappa^2/D^2$ by the same bounded curvature of the coarsened rows. Choosing the error probability small proves the claim. Even acquiring a constant fraction of this one bit's mature value takes $\Theta(D/\kappa^2)$ ordinary pairs. Its acquired value is much smaller than that of the whole dictionary.

**A limit on interpreting covariance rank as attainable memory.** Fix $D,b$, give the assignments their uniform prior, take $\kappa\downarrow0$ at fixed $n$, then take $n\to\infty$. The fraction of full additional gain retained in $b$ bits tends to the fraction of variance explained by the optimal $2^b$-point squared-error quantizer of a standard $R$-dimensional Gaussian. To prove this, the log gain at weak contrast is a common factor times the expected squared conditional mean of the first derivative of $m_n$. At zero contrast the derivative is $\lambda P\sum_i e_{T_i}$, with a loop contributing zero and each unordered edge occurring with probability $2/D^2$. This follows by differentiating the product likelihood and subtracting its common normalizer. The reference pair weights tend to the uniform pair weights. For fixed $n$ there are finitely many tapes and deterministic encoders, so the weak-contrast limit commutes with the maximum. After normalization by $\lambda\sqrt{2n/D^2}$ the derivative converges to the standard Gaussian on $\ker B$ by the multivariate central limit theorem, with matching second moments. This is convergence in quadratic Wasserstein distance. The optimal root-mean-square quantization error varies by at most that distance, by coupling and the pointwise Lipschitz property of distance to a fixed set of centers. Conditional means attain the best squared-error reconstructions.

The Gaussian fraction is $\Theta(\min(b,R)/R)$ for $b\ge1$. For any message its captured squared norm is at most $2I(G;Z)\le2b\ln2$, using the Gaussian linear moment-generating function in the entropy variational bound for each conditional mean. Storing the signs of $\min(b,R)$ orthogonal coordinates gives $2\min(b,R)/\pi$ captured squared norm. After one isolated raw observation, encoders instead attain order $\min(2^b-1,R)/R$ of the available information. After learning the full dictionary the fraction of the mature information is of order $\min(b^2/R,1)$. These statements use three explicitly different training regimes. A single fixed bit budget need not have one predictive distortion that applies throughout learning. ## What must persist from one task to a task with a new orientation?

The task distribution can change a hidden orientation while retaining a common unknown transformation. Score the second ordinary response of a fresh subject after the first response is observed. In the binary lag-mask family one response in each training subject gives no information about the reusable mask. Two linked responses suffice, at a signal-dependent sample price. With $H$ equiprobable masks, $b$ learned bits and a shared decoder, the largest possible expected log gain after mask identification is $\min(1,2^b/H)C(a^2)$. This supplies a finite transfer witness with ordinary training, a declared environment change and a physical communication budget. The claim is limited to that change, fixed horizon and task-family prior.
