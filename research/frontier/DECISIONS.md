# Research decisions

| Question | Decision and evidence |
|---|---|
| What stays canonical? | Foundation R4 on `main`. Both R4 and a conventional finite-state table realize the data-inferred six-state predictor. No matched language or device result supports replacing either with this candidate. [Comparison](EVIDENCE.md) |
| What did the first reconstruction settle? | Retain the value-channel and access assumptions on its address-process theorem. Retain the exact fixed-mixture text certificate, including the use of hindsight and its original development suffix. [Historical scope and replay](../../README.md) |
| What actually emerged? | Retain continuation predictions as intermediate values for the two-level sequence experiment. Ordinary outcomes determine whether an update copies one bit or combines several. The six-state source proves a strict predictive gap at width three. [Derivation](FOUNDATION.md) · [Exact loss gap](OBSTRUCTIONS.md) |
| Which physical realization wins? | Leave this observer-dependent. The six-state indexed automaton uses a single table lookup per letter. Caching a fourth bit gives pure signed reads. The three-bit construction pays for a sum. Training acquisition dwarfs all three small deployed models. [Resource comparison](EVIDENCE.md) |
| Does one learner explain continuous features and all composition? | Retain alternating ridge fitting as a serious pairwise alternative. It learns continuous factors from ordinary responses and has an exact initialization-dependent limit. Finite-cost composition beyond the supplied pair cut is open. [Learning dynamics](FOUNDATION.md) |
| Can general passive coverage be cheap? | Reject the uniform claim. A rare exceptional word yields an exponential identification cost. In rank one, an explicit linear-span criterion permits cheap extrapolation on supported designs and proves its failure on others. [Obstructions](OBSTRUCTIONS.md) |
| Does density explain attention? | Retain the sharp three-quarter result only for exact binary-valued linear state and signed address instructions. Soft attention, efficient identification of useful features on natural data and general FP replacement remain unresolved. |


The single-stream extension retains ordinary predict-then-observe training and removes external episode/label markers. A probability grid lets the same closure execute multiclass conditional values exactly. A conventional table remains a strong alternative and won the independent ternary comparison with half-count smoothing. The dense all-context acquisition law needs $K^L$ visited contexts; the original million-token training view cannot cover every pair of 50,257 symbols. The size of an original-vocabulary acquisition path now matters more than another small grid case. [Single-stream evidence](EVIDENCE.md#self-driven-next-token-streams)


Retain the priced successor rows as a reachable full-vocabulary value-learning control. They beat the complete fixed lag-mixture lower bound with about one megabyte of additional row payload. An ordinary interpolated bigram is the identical conventional model. Its one-step state overwrite precludes using this gain as evidence for deeper compositional discovery. [Text certificate](text_result.json)


Materialization now has an explicit optimizer for priced signed registers and shared scratch. Changing the prediction basis reverses one fixed-basis decision. Even the best tested basis adds the fourth value when two distinct letters frequently demand it. The four-state counterexample rejects one-at-a-time feature admission. The exponential suffix orbit limits an eager implementation. [Proof and scope](FOUNDATION.md#when-does-the-learner-materialize-an-extra-value)


Retain partial-orbit discovery for the fixed-basis cost observer. It bounds any remaining deployment saving and can return a valid layout before enumerating exponentially many columns. Basis discovery from passive natural inputs and repayment of total acquisition work remain separate questions. [Exact early-exit evidence](discovery_result.json)


For finite probability registers retain the sharp affine occupancy law. For continuous, constant-preserving value maps on the complete cube, convex mixtures follow. Approximating a soft mixture by rounding can have small predictive error even where exact grid preservation forces a hard address. The semantic assumptions and horizon determine which conclusion applies. [Finite grids and the continuous limit](FOUNDATION.md#exact-finite-grids-and-the-continuous-limit)
