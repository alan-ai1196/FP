# Research decisions

Foundation R4 remains canonical on `main`. Its positive evaluator and a conventional indexed state machine both realize the learned six-state law. The current text results favor the historical Transformer and modified Kneser–Ney. Replacing R4 would require a stronger matched language and physical result. | Question | Decision and scope |
|---|---|
| What survives the first reconstruction? | Preserve the address-process theorem's value and access assumptions, and the 513-source fixed-mixture text certificate with its original exposed suffix. [Historical replay](../../README.md) |
| Can labels create a reusable transformation? | Yes on the finite sequence sources studied here. Three continuation bits attain a strict predictive gain over signed copying at the same width. Dense passive acquisition can cost exponentially more than executing the resulting model. [Recovery](FOUNDATION.md#a-native-linear-update-learned-from-scalar-labels) · [Lower bounds](OBSTRUCTIONS.md) |
| When should a learner store a new intermediate? | Price the actual dependencies and workload together. The exact register optimizer can admit two individually costly values, and a partial search can certify a layout without expanding every continuation. An indexed state table remains competitive. [Physical selection](FOUNDATION.md#when-does-the-learner-materialize-an-extra-value) · [Search costs](discovery_result.json) |
| How general is factor learning? | Alternating ridge regression genuinely learns continuous pair factors. Its limit depends on initialization. Compositions outside the supplied pair decomposition require further evidence. [Dynamics](FOUNDATION.md#a-genuinely-different-optimizer) |
| When does addressing follow? | Exact affine maps on dense finite grids obey a sharp occupancy restriction. On the full continuous cube, constant-preserving probability maps are convex mixtures. Softmax attention and efficient feature acquisition on natural sequences remain open. [Grid theorem](FOUNDATION.md#exact-finite-grids-and-the-continuous-limit) |
| What can be learned from a single stream? | Finite-memory multiclass laws admit learned recurrent updates. An ordinary smoothed table won the ternary control. The full-vocabulary successor learner beats the historical fixed-mixture bound and is mathematically an interpolated bigram. [Stream controls](EVIDENCE.md#self-driven-next-token-streams) · [Full vocabulary](EVIDENCE.md#original-full-alphabet-successor-values) |
| Can a new symbol be learned from sparse uses? | In an accurate basis, the span of observed one-occurrence contexts determines the identifiable predictions. The unconstrained estimate can be unstable after sampling. A bounded scalar fit wins the matched prospective comparison on a source with one-dimensional predictive geometry and has an exact two-state categorical counterpart. [Sparse acquisition](EVIDENCE.md#learning-a-rare-action) · [Stable composition](EVIDENCE.md#stable-scalar-composition) |
| Which memory helped on text? | The scalar smoother selected overwrite. A delayed token-group bit improved the frozen reporting score. The training-learned partition lost to the frequency bit and a resource-matched raw trigram. Both tested group interfaces leave the Transformer below their oracle loss floor. [Scalar study](EVIDENCE.md#one-learned-group-on-the-original-stream) · [Partition study](EVIDENCE.md#learning-a-distinction-on-the-original-stream) |
| Can the output distinction itself be learned? | A pooled binary-history objective has an exact threshold optimizer. With context-dependent decoding, even two successors per context give a weighted Max-Cut objective. A constructive half-weight guarantee applies to fitting that restricted class. Its prospective predictive value is unresolved. [Derivation](FOUNDATION.md#learning-the-output-distinction) |
| Did the conditional bit justify its cost on later data? | Direct exchange learned a bit with lower raw NLL than the frequency bit and sparse trigram on the next 131,072 original training-file targets. The registered storage prices reverse those two comparisons. The simultaneous lower bounds leave acquisition work unpaid. [Prospective results](EVIDENCE.md#prospective-transfer-to-the-next-training-file-block) |

## Objective and literature-driven comparisons

Use separate predictive, emergence and interactive claims, each with a budget and a specified observer. Retain the finite-state learner and the order-two counterexample as controls. A bound on conditional loss under a logging policy transfers to decisions only with action coverage. A later task can also change what state was worth constructing before it was known. The seven-bit parity theorem supplies an exact optimum against arbitrary finite encoders. Its Hamming construction is a comparison target for learning.
