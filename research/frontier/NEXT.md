# Next mathematical attack

The repeated-name result separates learning an arbitrary lookup from locating individual errors. It still supplies the names and permits any stored table. A more decisive question is when ordinary prediction labels force a learner to construct an internal state space with unknown dimension, equivalence classes and token updates. [One-way observation result](FOUNDATION.md#recovering-a-clean-lookup-without-locating-the-raw-errors)

## Which computations can an ordinary rare next token force a learner to construct?

A prefix accumulates named binary toggles. One query reveals a binary target; its probability rises on an unknown affine flat of reachable vectors. Derive the smallest causal state that can predict after every future toggle. Determine what a learner must observe to discover the state's dimension and transitions, including the difference between noiseless labels, independent background errors and an unrelated target with the same marginal prevalence. Compare learning and deployment resources with a direct named table.

## Frozen registrations

### Learning the update that predicts a rare ordinary token, 2026-11-25

For a clean sample, use $n=12$ raw bits, codimension $r=2,4,8,12$ and fresh seeds 64–95. Generate independent uniform full-rank defining parity rows and a uniform right-hand side with NumPy [seed,n,r,8421]. Uniform training vectors use [seed,n,r,8422]. A learner receives only the vectors and their ordinary clean membership answers. It keeps one positive origin and a basis of subsequent positive differences, and stops after eight consecutive positive examples in its current affine hull, resetting the counter on a genuine extension. Record the number of ordinary labels consumed, learned rank, exact flat recovery and executable update size. No rank or positive-point oracle is given to the learner.

In the noisy raw-stream test use $n=6$, $r=2,3$, fresh seeds 64–79, and a flip probability of 1/8. Draw the true flat using [seed,n,r,8421] as above. As a control draw a uniformly random subset of the same size using [seed,n,r,1,8421]; do not reject an accidental flat. For each source, generate 512 independent episodes from [seed,n,r,kind,8423]. Emit six fair raw bits in order, followed by independent symbols chosen with probability 1/2 of a query and otherwise a uniform named toggle. Emit the noisy answer as an ordinary zero/one token after the query, then restart. The trainer reconstructs each vector from the raw prefix and its actual toggles. Predict the next token causally on the original nine-symbol vocabulary. All methods use the same known input schedule and noise rate. No learner receives the true rank, transforms, positive classes or source family.

At cumulative budgets 32, 64, 128, 256 and 512 ordinary answers, compare the uniform-prior mixture over all affine flats, a Bayesian lookup mixture over all fixed-size subsets, and the equal-weight evidence mixture of the two. Both families have identical priors over sizes: equal weight to zero and each power of two through 64. Within each size use the uniform prior. Retain the highest posterior individual flat and its minimal toggling program as a hard installation control. Evaluate exact expected query log loss over uniform reachable vectors, full raw-token gain against the common marginal head, correct identification of the hidden set, mixture posterior on geometry and storage cost. Apply the same positive Q16 full-alphabet floor to all delivered forecasts. Compare the exact installed update to direct membership on every short continuation, check a historical R4 encoding of a learned raw-stream example, and verify small priors, posteriors and affine enumerations independently. The geometry and input operation are explicit assumptions shared by the candidates; evidence of useful creation requires learned distinctions that compose across histories and real costs for finding them.
