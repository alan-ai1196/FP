# Next mathematical attack

The frozen two-coordinate correction saved loss on four new text blocks. It learned from the difference between an observed raw word and the Transformer's probability of that word class. A base model that exposes only draws gives the learner different evidence. What is the price of replacing a probability read with purchased samples while preserving a normalized predictor or an actual generator? [Frozen two-file result](EVIDENCE.md#two-learned-error-coordinates-transfer-to-a-separate-text-file)

## Sampling access to a base predictor

Freeze the packet selected at cap two with installed-plus-live rent, raw GPT-2 IDs 13 and 198 and rate $1/512$. On the two already reported tapes replay each existing warmup and both reporting blocks. Compare exact probability access, one independently sampled base word per update, and 4, 16 and 64 independent samples. The count vector may be drawn directly from the equivalent three-class multinomial. Use seeds 211, 401, 587, 821, 1033, 1301, 1553 and 1789. Compare unrounded binary64 carry and the registered signed Q15 carry. Keep the realized observed tape fixed while varying only the independent samples used to estimate the class expectations. Evaluate every normalized output under the actual Transformer; no new text-transfer claim follows from reusing these tapes.

Derive a bound for the expected additional cumulative NLL of unbiased sampled updates on an arbitrary fixed transcript, including the leaky memory time constant, fitted gains and sample count. Keep finite grid effects distinct. Check the inequality by summing all sample outcomes for short, nonstationary examples. Derive an exact accept/reject generator with access only to raw base draws, the active slopes and its own previous state. Price its expected proposals per output. The comparison of probability forecasts can use an external evaluator which sees more of the base model than the sampler does.

Exercise the learned computation through true autoregressive generation by the archived Transformer. Start four independent streams from the 256 observed tokens preceding validation positions 65,536, 81,920, 98,304 and 114,688. Initialize the small state at zero for this new generation test. Generate 128 raw words per stream, feeding each emitted ID back through the 256-token rolling Transformer, using rejection sampling and one further independent base draw for each state update. Freeze seed 71209. Compare the actual dense raw-word law against the sparse formula at every release and verify the replayed integer state from the accepted IDs and purchased base samples. Record distribution identities, paid draws, execution cost and an output digest. The test establishes a generative implementation and an access tradeoff. Judging generated text quality is a different experiment.
