# Next mathematical attack

When can a learner keep a smaller state after an observation and still perform every future learning update? The four-ticket experiment retained a posterior over 24 hypotheses per word group. Its current actions could use a 4-by-4 matrix of ticket-to-word probabilities. A conceptually different candidate is to acquire a basis for the changes in log probabilities that ordinary feedback actually makes. A repeated update could then change a small vector of coefficients. The number of reachable directions, the program retained to decode them and the cost of extracting a forecast all matter. [Action acquisition under censored feedback](EVIDENCE.md#learning-unfamiliar-action-meanings-from-purchases)

## Prospective test of learning a smaller update state

Freeze this protocol before reading tape positions at or after 5,275,648. Preserve the earlier registered action and text results. Use the earlier four-word groups, floor $1/32$, censored purchase rule and frozen predictive priors. Test the following learning rule on actual new feedback.

1. Use 65,536 disjoint triples starting at 5,275,648 for discovery. Offer the first 512 eligible contexts per group. The old reuse word prior predicts word identities. New unknown ticket meanings and offers use independent PCG64 streams, with the quarter-floor acquisition menu. A generic learner starts with no update directions. When a bit is purchased, it may see the single vector of its log likelihood across 24 anonymous hypothesis columns. The fixed column permutation is shared by both groups and later deployments. It may use neither the ticket-to-word assignments nor the known dimension of their update space. Subtract the first hypothesis coordinate, orthogonalize the remaining 23 entries twice against the existing directions, and install a unit residual direction if its norm exceeds $10^{-9}\max(1,\|x\|_2)$. Passes convey no bit. Visit the two groups' opportunities in round-robin order. Freeze independent snapshots after 8, 64 and 512 opportunities per group and record rank, purchases and payload.
2. Follow with four disjoint panels of 32,768 triples each. Each has new hidden permutations and new offers. For the first 512 opportunities per group, transfer the frozen basis to the pooled, global, directly fitted rank-one and separately fitted word priors. Start each new belief from the same uniform prior. After each actual purchase project the centered anonymous log-likelihood vector onto the frozen basis. Track the coefficients and reconstruct forecasts for all four names. No new directions may be added on transfer. Compare with unrestricted 23 log ratios, the conventional full posterior and a hand-derived $(4-1)^2$ log-odds table using the semantic assignments. Each policy chooses its own purchases under the same offers and receives feedback only for its choices. Measure per-opportunity forecast deviation, first differing decision, number of purchases, feedback mismatch, realized payoff and maximum projection residual. Also run the first four directions from the final basis as a capacity control. A frozen basis whose decisions diverge must report the divergence.
3. Give the mathematical criterion for present forecasts to determine future updates on the reachable set. Attack it using arbitrary priors with the same marginals, finite precision, positive likelihoods, varying $K$ and expensive decoders. Verify the assignment dimension by exact finite calculations. Compare a subset dynamic program for weighted permutations with direct enumeration. Test whether two full binary64 marginal matrices can coincide while a common future feedback sequence makes their predictions diverge.
4. Count the learned basis, per-stream coefficients, any extra column-order storage, common forecast/hypothesis tables and temporary work. Compare direct storage, a shared learned basis, and a semantic log-odds table at 1, 8, 16 and 64 simultaneously retained group beliefs. Use a two-byte format descriptor for a learned basis and keep its FP64 reconstruction matrix once. The anonymous interface order is common across generic methods. Report native or compiled inference/update timings on identical purchased-bit work. The compact measure must preserve the ability to update on fresh feedback. A state saving that only works after learning is frozen addresses a different observer. A successful result still assumes the finite likelihood bank was supplied.
