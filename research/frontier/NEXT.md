## Selecting and transferring sparse recurrent coordinates

Derive the raw loss change of any subset, including cross-coordinate normalization, and the minimal real-linear state dimension when all zero-sum error directions are reachable. Construct nested subsets by forward addition and backward deletion using exact realized training NLL with the fitted coefficients held fixed. Include empty and full models and verify the best subsets of sizes one, two and three by exhaustive training search. Choose on the original selection block only. Report the best admissible subsets at maximum sizes 1, 2, 4, 8, 16 and 33, using the historical per-bit installation rent, and separately including live-state rent. Compare binary64 and signed Q15 per retained state. The Q15 grid covers $[-1,1]$ with zero exactly representable. A sparse packet must transmit the active raw token IDs and slopes. Keeping the complementary class requires accounting for the remaining IDs needed to determine its mass. Compare the full frozen diagonal and the frozen single projection to the empty correction without any new fitting. This follow-up was designed after seeing the preceding reports.

Freeze all policies before computing risks on two new tapes. On the training file score two adjacent 32,768-word blocks starting at 8,568,832. On the separate original validation file score two adjacent 32,768-word blocks starting at 65,536. Its prefix through 131,072 words has SHA-256 a2a7b20166f93aea0f345d25c3543b0079348de283b87d6a627075dc6d1b7b48. Each tape permits 4,096 preceding targets to warm the frozen state, starting from zero. Only byte identity has been checked in the new regions. Use the same actual Transformer with rolling context 256. Price sparse forward work, dynamic storage and any access to the rest of the named class masses. Report incremental raw-word losses separately on all four blocks, including models selected before the first Transformer report.
