# Next mathematical attack

When can ordinary observations identify a computational state whose response to each token is to retain, reverse or erase a previously learned distinction?

Every deterministic update of one bit has exactly four possible actions. The previous text experiment forced each new stored bit to be a function of one token. Its learned membership table consumed most of the extra cost beyond a raw trigram. A reusable bit can persist across many tokens if the observations identify its transitions. Derive a criterion in terms of observable next-token distributions, an estimator and the cost of learning it. Distinguish actual synchronization from forecasting with a continuous posterior over an unknown bit.

Examine an unsegmented positive two-state sequence source. Test whether the rank and orientation of probability blocks distinguish reset from permutation, and whether those signatures suffice to validate a two-state deterministic update. Construct a rank-two stochastic counterexample if they do not. Give the same raw observations to a conventional categorical or spectral learner. Test exact population identification, noisy finite acquisition and an ordinary order-one successor baseline before drawing any broader language or runtime conclusion.

## Registered one-bit source

Use four symbol IDs. In their declared order the hidden updates set zero, set one, retain and reverse. The two positive emission rows are $(1,1,5,1)/8$ and $(1,1,1,5)/8$. The generator starts in stationarity. The learner receives only the token stream, alphabet, two-state class and a declared emission floor of $1/8$. It has no state labels, reset cue, prefix dictionary or hidden graph. Choose the prefix/suffix anchor pair with the largest positive adjacent empirical covariance on training, resolving ties in ID order. Classify a putative reset when the absolute determinant ratio is at most half the square of the declared floor. For an estimated reset and its one-letter continuations, use the minimum and maximum observed anchor forecasts to orient the two possible states. Fit per-state emission counts on a causal replay after the first learned reset, with add-one smoothing. A failure to synchronize or distinguish two endpoint forecasts uses an ordinary successor fallback.

Test an exactly balanced stationary triple tape and a single sampled stream with seed 120311, 65,536 training and 16,384 later targets. Report whether all four transitions match up to state renaming, and the frozen next-token losses. Compare a smoothed successor, an exhaustive conventional two-state deterministic-transition learner searching all 256 tables from the same raw training tokens, and the canonical positive evaluator on the derived graph if available. The positive arithmetic cost must include initialization, delay and normalized four-way readout. Test a genuinely stochastic rank-two source with a singular reset and three distinct subsequent predictive states. The exact characterization must reject it. A useful structural result must explain why the distinction survives for all continuation lengths on the declared family.
