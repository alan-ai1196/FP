# Next mathematical attack

Can ordinary token errors teach **both** the earlier-history distinction and the set of output words it changes, without a supplied word group, a library of likelihood models or a word-identity target for the distinction? The preceding learner found a compact state for continued adaptation. An outcome-blind control found the same update space inside the supplied bank. The present test must therefore change which predictive directions exist. It acts directly on a positive full-vocabulary distribution learned from raw text. [Update-space result and its control](EVIDENCE.md#can-feedback-teach-a-smaller-state-for-future-updates)

## Prospective test of learning both sides of a text correction

Freeze this design before inspecting raw tape positions at or after 5,865,472. Study a positive pooled bigram $p_q$ from the original prefix. For free sets of raw earlier types $A$ and raw outputs $B$, multiply the probabilities of members of $B$ by $\rho$ if $u\in A$, then renormalize. No vocabulary subsets, tags, previous output identities or individual source forecasts are supplied as target classes. A global control applies a learned output set on every history.

1. Fit on the next 262,144 consecutive targets, select by priced full-vocabulary NLL on the following 131,072, then report four further 131,072-target blocks. The previous two raw tokens are available at every forecast. The primary installation cap is 4,096 bytes above the common raw bigram, including the 2,584-byte calibrated base, readout headers, lists and any carried address. Use the historical rent of $(\ln2)/256$ nats per installed or carried bit per 131,072-target deployment. Compare unpriced NLL as well. Never supply a free query-by-class normalizer table to the executable model.
2. For fixed $\rho\in\{1/2,3/4,3/2,2\}$ and fixed output set, choose up to $k_A\in\{64,256\}$ active raw types from their positive net whole-observation gains. Pay 16 bits per list member, scaled by fit length over deployment length during training. For fixed histories the output objective is modular observed gain minus the sum of $\log(1+(\rho-1)p_q(B))$. Use its tangent at the old set to obtain a separable upper bound on loss. Minimize that bound under the 16-bit member prices and $k_B\in\{1,32,256\}$. Keep the old set on equality and retain a best fitting iterate. Alternate for at most twelve rounds. Initial active histories are all training tokens, the most frequent types carrying half the historical count mass, and the two low-bit partitions of raw IDs generated by PCG64 seeds 17 and 29. For each start form a singleton seed from the output with highest signed observed-minus-expected count on that active partition. Also try the priced tangent set from the empty output set. All output scans cover all 50,257 candidates. Offer the unchanged model. Validate singleton, multiword, global-only and current-token-only versions separately. The current-token control uses $q$ wherever the other encoder uses $u$.
3. Fit a conventional gated log-linear readout with individual output odds under the same overall byte cap. Use the earlier-type binary gate and free log odds for up to 32, 128 or as many named outputs as the cap allows after reserving its gate. Initialize the gate from the best fitting two-set candidate for each history cap and also from the most frequent historical types up to that cap. Propose output supports by absolute conditional actual-minus-expected counts at those active histories. Fit penalized categorical likelihood with log odds bounded by $\pm\ln4$ and an additive sum of squared log odds. Round odds to positive multiples of 1/1,024. Alternate refitting the eligible raw histories and output weights for up to four rounds. Include its empty model. Compare these conventional independent output weights to the shared multiplier and equal-price raw counts.
4. Give a calibrated whole-row raw trigram the original count table and, as a separate option, one fitted on the first three quarters of the new fit. It buys rows on the final fit quarter and uses the same selection block. Try its established smoothing masses. Evaluate at 4,096 bytes and at the actual selected multiword installation size. Also report the frozen historical modified Kneser–Ney five-gram and Transformer on the first 4,096 targets of each reporting block, and compact forecasts on those same positions. These larger anchors have separate costs.
5. Report the learned IDs, active sizes, learned odds, selection and deployment results, event coverage, and whether the class beats a single learned output, a global correction, the current-token gate, individual odds, and matched raw contexts. Verify full-alphabet normalization and the monotone tangent descent independently. Include an exact small case where neutral or alternating learning stalls, the tractability distinction between fixed-history and joint optimization, and actual normalizer work. For physical replay compute the set's pooled backoff mass once and charge the representation. Count or search the installed output set against each active query's raw sparse bigram row. Independent native replay must return the same observed loss per target. A faster implementation with additional mass caches must account for them separately.
