# Next mathematical attack

## Can raw language learn when a predictive state should persist?

The cycle separates useful observation duration from algebraic state count. Return to ordinary full-vocabulary text and ask whether the learner can acquire a raw-word-dependent lifetime for a predictive distinction. Give it a strong literal context predictor and learn both latent lexical rows and the transition probabilities using the next-token objective. [Which uncertainty survives](FOUNDATION.md#which-coordinates-of-a-phase-distribution-can-ordinary-future-words-see) · [Earlier deterministic word-update control](EVIDENCE.md#learning-which-raw-words-preserve-or-erase-a-bit)

### Registered chronological comparison

Use the two existing hash-checked 65,536-token reporting windows in the raw-word action study, scoring all 50,257 outputs. They have been used by earlier investigations. From the training file, starting at token 9,000,000, fit the background on 524,288 tokens, the latent models on the following 262,144, and select on the following 65,536. Use the two preceding observed raw names for each target and initialize the hidden probability to one half at the start of each fit or score window. Freeze every parameter before reporting.

Fit the add-half background unigram and recursive literal bigram and trigram distributions, using 16 pseudo-observations of the lower-order law at each context. At hidden state $s$ score $(1-\lambda)b_{\rm trigram}(y\mid u,v)+\lambda f_s(y)$, with $\lambda\in\{1/16,1/4\}$. The initial hidden state is uniform. After the emitted word $y$, switch the binary state with probability $r_y$. Compare three models: a pooled lexical row, two rows with one learned switch probability, and two rows with learned switch probabilities for the 256 most frequent background words plus one shared tail. Fit 12 forward–backward EM iterations per setting, with 64 observations from the base unigram smoothing each lexical row. Use a switch prior adding 16 trials at rate $1/32$ to each fitted switch bin. Initialize the two rows from the earlier and later halves of the latent fit, or from even and odd 128-token blocks. Select initialization and $\lambda$ by validation separately for each family. Report all three conventional backgrounds and all three latent families.

On each report record cumulative and eight contiguous block losses, the range of learned switch values, the loss of replacing all fitted token switch rates by their training-frequency-weighted average while leaving both lexical rows fixed, and exact-filter versus four-bit deterministic and randomized forecasts of the selected word-dependent model. A difference between two fitted lexical rows alone cannot establish useful state persistence. Report actual fitting passes, stored tables and streaming work, and distinguish the corpus results from guarantees for the supplied clock family.
