# Next mathematical attack

Can a learner acquire the history distinction that matters to its *available future readouts*, with a cost certificate that remains useful on ordinary text? Acquiring a globally optimal single bit is already NP-hard on explicit positive rows at inverse-polynomial precision. On the other hand, a shared affine direction in the conditional probabilities permits a sorted threshold algorithm. The one-dimensional total-variation diagnostic on the actual FineWeb-Edu calibration rows gave a radius of 0.527 and no informative excess-loss guarantee. [Acquisition boundary](OBSTRUCTIONS.md#acquiring-one-predictive-bit-can-encode-minimum-bisection) · [Sufficient geometry](FOUNDATION.md#when-one-predictive-bit-can-be-learned-by-sorting) · [Natural-text evidence](EVIDENCE.md#learning-a-shared-bit-of-three-text-tokens)

The next mathematical attack is to measure differences in expected log loss between deployable readouts. A high-variation query coordinate can be irrelevant when all those readouts agree on it. Conversely, a bit with zero marginal target information can be necessary after a query arrives. Seek a learnable low-dimensional order or an obstruction in this readout-dependent geometry. It should explain which quantities ordinary observations identify, which history updates can maintain the selected distinctions, and what the learner pays for installing and executing them. Compare against a conventional calibrated conditional model using the same observed data and access to historical tokens. The previous two text experiments give concrete negative controls for reusing a frequency lag. Any new language prediction claim needs a prospective evaluation on later observations.

## Prospective full-vocabulary test of learned token addresses

Use the pinned FineWeb-Edu training stream. For target $y=x_t$, the history type $u=x_{t-2}$ is available when its single-bit address is formed, and the subsequent raw query $q=x_{t-1}$ is known when the full-vocabulary forecast is issued. No past-token tape is available to the deployed added state. The hypothesis is that differences in the actual log loss of two conditional readouts can teach a token-to-bit map which pays for itself on future observations.

1. Fit the existing smoothed bigram on positions $[0,786432)$ with 50,257 token IDs and smoothing mass 64. The 512 most frequent raw targets receive individual backoff masses. The rest share a mass with fixed within-tail ratios proportional to add-one unigram counts. Ties use the smaller raw ID. A conditional readout replaces the unigram backoff in every bigram row by this full-vocabulary distribution. It combines observed pair counts with the 64 units of backoff exactly as the common model does.
2. Fit two such backoff readouts on targets $[786432,1048576)$ using the previous raw type's frequency-group bit as a supplied seed at lag two. The existing group contains the most frequent types covering half the training tokens. Also fit a pooled readout on the exact same targets. Start the category masses at their baseline unigram values. Run 16 expectation-maximization steps with 2,048 baseline-proportional pseudocounts per readout, then quantize 513 category masses to positive integers summing to $2^{24}$. The high-frequency list and seed give the learner an initial representation. Later token assignment receives no membership labels.
3. Freeze the readouts. For each raw history type, sum the realized log likelihood ratio of readout one to readout zero on targets $[1048576,1572864)$. Accumulate the squared log likelihood ratio per observation for a reliability adjustment. Try default zero, one and the original frequency bit. Flip an address when its evidence exceeds the address rent plus $\beta$ times the square root of its sum of squared log likelihood ratios, $\beta\in\{0,1,2\}$. Try sorted 16-bit exceptions and a dense bitmap. Each bit costs $(\log2)/256$ nats over 131,072 deployment targets, with four times that rent over the four-block acquisition sample. Dense addresses have zero marginal address rent. Encode each constructed map in the least expensive of these formats. The control that ignores the query during address fitting uses the likelihood ratio of the two backoff distributions alone, then deploys exactly the same conditional readouts.
4. Charge a 24-byte header, two-byte raw IDs and three-byte probability masses for the 512 named outputs. The last mass is implied by normalization and cached in the header. Each nonconstant route pays one live byte plus its sorted two-byte exceptions or rounded dense bitmap. Frequency membership is computed from already retained unigram counts and a boundary count/ID in the header. Constants install just one probability row. Select independently within the conditional, query-ignoring and constant families by priced full-vocabulary NLL on targets $[1572864,1703936)$. Freeze each result and report on $[1703936,1835008)$. Ties follow the order in this registration with smaller $\beta$ and sparse format first.
5. Compare the raw bigram, tuned constant, unchanged seed, conditional learner, query-ignoring learner, and a full-vocabulary interpolated raw-token trigram. Fit trigram counts up through position 1,048,575. Try smoothing masses 4, 16 and 64 on top of the common bigram. Prune entire context rows by purchase-block likelihood gain at the conditional learner's storage cap, with a 12-byte index record per pair and six bytes per observed successor. Charge 11 bytes for metadata and the second history token when nonempty. Optimize total empirical gain less the same rent by integer knapsack with score rounding at $10^{-7}$ nats per row over the acquisition sample, then choose smoothing on the selection block. Report the unpruned trigram separately. The preregistered formation criterion is a changed address map and lower priced held-out loss than the supplied seed, the best constant and the common bigram. Incremental value from query-aware training and competitive performance against the matched raw trigram are two further, separately scored comparisons. Report all outcomes, actual bytes and acquisition and replay cost. This is a continuation of the training file.
