# Next mathematical attack

When is discarding raw distinctions safe across a declared family of decisions? A shared equality predicate can replace quadratically many individually listed repairs in a balanced population. Nonuniform joint usage can overturn their price even when each individual raw token is equally frequent. The natural-text results also show that validation can prefer the smaller, history-independent law. A predictive improvement for one event provides little information about the value of a representation for a new decision. [Cost theorem](FOUNDATION.md#a-price-for-copying-an-interaction-across-raw-token-types) · [Counterexamples](OBSTRUCTIONS.md#the-cost-of-repairing-an-interaction-one-cell-at-a-time)

## Mathematical target

For a finite family of contexts, specify what each local decision can observe, which distinctions a proposed state discards and which outcomes and actions determine reward. Characterize the worst possible difference in bounded expected loss between decisions allowed to use raw observations and those restricted to that state. Test whether a single distribution of local reconstructions shared across all contexts gives both a sufficient condition and a necessary one. Include a criterion for the computational cost of checking the condition and a finite-sample bound if it can be estimated from observations. Match the general conclusion to ordinary next-token log loss with its actual score range. A one-stage decision certificate would still leave recurrent composition and transfer to unobserved tasks open.
