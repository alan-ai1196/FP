# Next mathematical attack

Can a learner discover a transformation for a rare token from ordinary contexts **before** it has labels for every short context or a full-vocabulary probe table?

The obstacle is specific. The signed realization theorem obtains every action from a complete block of prefix/suffix forecasts. The priced discovery theorem saves work after such a basis exists. A million tokens do not cover all 50,257² two-token contexts. The successor-table control earns a real score gain but overwrites all prior state. None provides a cheap route to discovering a rare action that composes with existing ones.

Investigate a token occurring once between already learned prefix and suffix transformations. Each ordinary scalar outcome provides evidence about one bilinear form of the new action. Characterize exactly which unseen compositions are identified by these observations. Include the cost of obtaining the old basis, give the conventional linear-regression comparator the same information, and test whether the identification result survives sign constraints, rank deficiency and two jointly unknown actions. A meaningful positive result should predict an unseen composition at a measured acquisition cost. Ordinary-text competitiveness would still require a matched prospective comparison.
