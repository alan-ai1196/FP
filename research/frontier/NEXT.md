## A small memory that improves several environments

The frozen cross-output text connection reduced the net savings on both fresh files. Ask for a common prediction improvement across specified sources. Study an encoder that writes one private randomized bit after an observed cue, discards the cue and forecasts a subsequent observed bit from memory. Training files are identified. The reader receives neither a source ID nor writer randomness beyond the carried bit.

Before measuring finite acquisition, fix independent one-step environments on $m+1$ equally likely opaque cues, $m=2,4,8$. In environment $i$, add $1/4$ to a fair successor's probability at cue $i+1$ and subtract $1/4$ at cue $i$. Permute the cue names and training-source order with a NumPy generator seeded by [25252026, m]. Give the fitter only the per-source ordinary cue/outcome counts. Use 4,096, 65,536 and 1,048,576 independent pairs per training source and seeds 117, 503 and 991. Simulate these sufficient counts by one exact-law multinomial per source seeded from [seed, m, sample size]. Fit a common signed cue value in $[-1,1]$ by maximizing its least empirical residual correlation across training files (linear programming). Round the bit-writing probabilities to multiples of $1/256$. Take a simultaneous 95% lower bound using the signed-cue union bound across all 27 fits, including all environments. Fit complementary probabilities in Q16 using that lower bound, rounded toward $1/2$. Compare the installed stochastic bit, exact population one-bit optimum, common deterministic-bit obstruction, pooled deterministic binary partition fitted by ordinary counts, and carrying the cue and averaging the fitted bit predictions exactly. Score every environment from its exact population law. On the largest calibration size for each fit, also replay 32,768 fresh pairs per source with separate cue/outcome and writer draws seeded by [seed, m, 252521, source index]. Charge carried states, installation and private random bits. Derive the smallest feasible state count for finite cue and output sets and check explicitly where a shared clock, accessible cue or identified report source changes the setting.

## Competing mathematical routes

Use the conditional variance of a sampled score to construct a tighter simultaneous acquisition certificate, accounting for dependence of future leaky memory on each sample. Compare against unbiased inverse-binomial score estimation and an accepted-word stochastic gradient. The fitting procedure should see ordinary words and base draws only. Give any pilot samples, candidate screening, normalizer estimates and history re-queries an explicit price. A useful test will compare an acquired sparse multicoordinate packet to the already frozen constant domain, the sample-only complementary-class fit, the exact-probability subset learner and an unmodified Transformer on **new** chronological targets.

Historical replay changes what a generator can implement exactly. A Poisson test gives the ideal unrounded update using random draws from past contexts. A fixed maximum number of queries to an unknown past Bernoulli probability cannot reproduce its nonpolynomial ideal tilt. Price the expected number of historical Transformer executions, their lookback distances and stored context bytes against approximate short-memory sampling.
