# Next mathematical attack

When does an ordinary learner pay to materialize an intermediate value and reuse it rather than recomputing it? The original-vocabulary control in the [evidence](EVIDENCE.md#original-full-alphabet-successor-values) justifies learning new values; its depth-one state overwrites cannot answer this question.

Use the inferred continuation columns as candidate bits. Keep the independent prediction basis available. On each letter, allow one shared transient calculation for any missing value requested by several next-state coordinates. Price every transfer and each resident bit. Derive an update from observed letter counts that decides which extra columns to maintain across time, paying also to update the extra registers themselves.

Before testing, predict a transition on the six-state law. With three units per destination transfer, seven per shared three-input synthesis, and zero fixed rental, maintaining the fourth bit is worthwhile exactly when more than three sevenths of the observed letters require that synthesis. Include checks at a tie, after a frequency reversal, and against exhaustive subset search. A hard simultaneous memory bound and arbitrary arithmetic factorizations are distinct questions.
