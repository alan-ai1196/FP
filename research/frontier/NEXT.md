# Next mathematical attack

Can ordinary predictive evidence teach a learner *which* parity computations to retain before it knows the next task? In the seven-input, one-raw-read experiment, a hidden four-bit synopsis has an exact optimum. A hand-selected Hamming basis attains it. The proof already allows nonlinear encoders and adaptive queries. [Model, optimum and physical costs](../../literature/research_connections.md#how-much-state-must-exist-before-a-future-query-is-known)

Start with the zero-dimensional binary subspace. A proposed new stored bit is a parity of the seven raw inputs. It can be computed by a row of switches and XORs. Charge the switch mask, learning passes, arithmetic, reads and persistent bits. Use ordinary episodes consisting of the original bits, a publicly specified future query and a noisy binary outcome. No stored-bit targets, codewords, syndromes or covering distances are observed. Compare with caching raw bits, an equally informed exhaustive linear search, and the hand-selected optimal construction as a diagnostic. The proof that a code attains the optimum does not identify it from labels.

First characterize the population landscape exhaustively. For each dimension-three intermediate reachable by one-generator enlargements maximizing the immediate loss reduction, determine whether a fourth maximizing enlargement reaches optimal loss. Include *all* maximizers. Publish a minimal failed path if one exists. The criterion is measured in next-token log loss. A symbolic coverage shortcut is allowed in the mathematical audit only, with an independent calculation from the conditional label law.

Then distinguish the population accessibility question from empirical learning. Specify a causal or batch training rule for choosing the transformations before testing. Account for the cost of constructing all tried representations and estimating their readouts from labelled episodes. A useful positive result must state sample requirements and reachability; a negative result must identify which additional forms of rearrangement could still work. Address reuse across genuinely held-out queries and the effect of changing the query distribution. GPU execution awaits a justified workload and an optimized comparator.

## Registered ordinary-data test, November 23

The population audit found greedy traps. Freeze the following finite experiment before generating examples. A hidden uniform permutation assigns each of 128 opaque query IDs a distinct seven-bit parity mask. The noise is an independent flip with rate $1/8$. Draw 256 independent uniform seven-bit inputs per ID in training and 128 fresh ones per ID in scoring. Use NumPy PCG64 with seeds 23112601 (key map), 23112602 (training) and 23112603 (held-out). The learner receives only raw input bits, ID and observed binary token during training. Retain the same noise rate in the declared model family.

For every proposed shared linear synopsis $C$, a per-ID probability readout may choose a fair guess or either orientation of a parity in $C+B_1$. Fit these choices to the training labels by scoring the corresponding binary probabilities. Compute all correlations by Walsh transforms of *observed signed label counts*. Compare a four-step greedy learner, exhaustive maximum empirical likelihood over all dimension-four subspaces, the best four individual raw cached coordinates plus one read, and an unrestricted raw-parity decoder with a separately charged input-reading budget. Resolve all layout ties by the lexicographic order of the sorted elements of each span and readout ties by mask then positive orientation. Report unused fair routes if present. The exact Hamming structure and the generative permutation are unavailable to fitting. Use the latter only after fitting to quantify clean recoveries.

Report the training observations, exact search sizes, state and route storage, forecast loss on every held-out token, number of queries learned, and the cost of acquiring the layout and readout. All IDs occur in training, so this tests transfer to fresh inputs and reuse across tasks. An arbitrary permutation makes unobserved key meanings unidentifiable in general. Training on whole-parity feature statistics is a deliberate algebraic inductive bias whose acquisition costs must be included. No general emergence claim follows from this experiment alone.
