# Next mathematical attack

Does the earlier token carry a useful correction **after** every history gets the best global learned word class, including after accounting for the latest token? On four prospective text blocks a smaller global 256-word correction beat a sparse earlier-triggered one at predicting the next raw token. The original sparse gate had neutral odds everywhere outside its active set. The missing comparison nests the global predictor exactly and learns only the exceptions. [First two-set experiment](EVIDENCE.md#does-ordinary-text-teach-both-sides-of-a-predictive-correction)

## Prospective nested calibration of one acquired word class

Freeze the following protocol before reading any raw target at or after 6,782,976. Keep the global output set from the preceding fit and its selection. Use the same 262,144 fitting and 131,072 selection targets. Neither learning routine may see the new reporting blocks. Score the next two consecutive 131,072-target blocks starting at 6,782,976.

1. Freeze the 256 raw output IDs of the global class. Fit its unconditional odds multiplier by full-vocabulary likelihood on the fitting block within $[1/4,4]$, then round the odds to 1/1,024 units. Retain the previous multiplier 1.5 as a separate reference. The output law retains every within-class and complement proportion of the same pooled bigram.
2. Above this global class, compare sparse corrections keyed by the current raw token, the earlier raw token, the pair of both raw tokens, and the product of one earlier and one current correction. Each defaults to one. Allow the nine multipliers $1/4,1/2,3/4,1,5/4,3/2,2,3,4$. For a fixed other factor, sum the exact realized binary event log improvement of each choice within each raw key. Subtract $\beta$ times the root of the sum of squared observation improvements for $\beta=0,1,2$, and the amortized entry rent. Take positive options under the table cap. Use two bytes per raw ID or four per raw pair, plus packed response nibbles, headers and the necessary earlier-history state. Stay within 4,096 total bytes above the raw bigram. For a single table, try a half capacity and the full available capacity. For two tables try 1/4, 1/2 and 3/4 of the available exception capacity for the current factor and the remainder for the earlier one. Try both orders, with four alternating fits, retaining the nested one-table alternatives. Select on full-vocabulary NLL plus the existing per-bit rent. The joint family's winner can therefore be simpler than a genuinely two-factor result; report the actual selected tables.
3. Include a two-table current-only alternative with the same grids, fitting process, orders and capacity allocations, to check whether additional current-token flexibility explains an apparent earlier-history gain. Include the previous matched and full-cap conventional raw trigrams without any retuning. Score the fixed five-gram and Transformer on the first 4,096 positions of each reporting block. As before, disclose the different training and deployment budgets.
4. Record pure probability and priced gains over the refitted global law, whether a genuinely earlier table survives after a current correction, and the paired advantage over the best current-only alternative. Report both blocks, coverage, installed and live bytes and per-target native agreement. Serialize all nonneutral IDs and response codes. For normalizer costs share the previously learned output membership set and recompute its query mass from the sparse base, charging any cache separately. The ability to reuse a full-vocabulary class still assumes its empirically acquired word IDs and the underlying bigram.
