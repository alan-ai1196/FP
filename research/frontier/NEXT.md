# Next mathematical attack

Does a learned scalar transition buy predictive information about an ordinary next token after paying for the best tested overwrite calibration? Also bound what any memory can achieve if it can change only one learned binary distinction.

Use the original 50,257-symbol data and exposed 12,288 reporting positions. Fit the full smoothed successor bank on the original first 786,432 tokens exactly as before. Define the in-group as the shortest list of most frequent fit tokens whose total covers half the fit prefix, breaking ties by token ID. Keep the bank's distribution *within* each group. From the next 131,072 training targets estimate each preceding token's group-success probability with the bank's group mass as a prior of weight 64. Round that value to the nearest interior point on a grid of denominator 4,096, half upwards. Denote this value by $b_x$ and the similarly rounded global add-one group mass by $\mu$.

Test a token-conditional affine update of one 12-bit scalar. For each of the two input groups choose $s$ from $\{-1/2,-1/4,0,1/4,1/2\}$. Advance to the rounded value of $(1-|s|)b_x+|s|h$, with $h=z$ for $s\ge0$ and $h=1-z$ otherwise. Give an overwrite control the identical search with $z=\mu$ on every step. Also score $b_x$ alone and the original full successor bank. Choose each family's coefficients on the last 131,072 training targets, scoring before observing the target. Charge three bits per nonzero coefficient and twelve additional bits for live recurrent memory, converting bits to nats. Break ties by smaller total absolute slope and then lexicographic slopes. Start each sweep at $\mu$. On development warm from the start of the same stream and keep the full context at the reporting boundary.

Success requires distinct reachable scalar values for at least one common observed last token and a strictly lower certified full-vocabulary loss than both the selected overwrite control and the original full bank. This is a limited comparison on exposed positions. Calculate two hindsight lower bounds with identical within-group probabilities, one allowing a different group rate per last token and one revealing the correct group on every prediction. A historical anchor below the latter bound excludes every computation acting only on this one group mass. Report failures, state and fit costs, and the mathematically equivalent conventional conditional smoother.
