# Next mathematical attack

Can ordinary noisy terminal labels distinguish a reusable value transformation from any register that only copies or negates a previous register? Use a reset word followed by a binary target. The learner receives the symbols, a physical capacity ceiling and the terminal outcome after its forecast. A hidden transition table belongs exclusively to the test generator.

Start with parity, then try a six-state source on three symbols. Measure the minimal deterministic state count, the dimension of the span of continuation forecasts and the number of distinct suffix forecasts up to a global sign. Test whether the last two can differ even when the source is fully identifiable. Charge the initial observation table as well as the fitted execution. A second learner with direct access to the same raw observations should be able to challenge any claimed advantage.

The next obstruction is passive coverage. Try to predict on unobserved words under a declared rank bound, then remove either the bound or the necessary input support. Check whether a lower-cost acquisition law can survive this attack in a nontrivial subclass.
