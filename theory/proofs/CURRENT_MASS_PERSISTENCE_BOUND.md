# Pre-context gain bounds from the owned positive masses

Status: **PROVED FOR DECLARED MASS BOXES; IMPLEMENTED WITH OWNED REFRESH;
EXACT AND BOUNDED CPU/CUDA AUDITS**. This is a stronger solver for an existing
persistence premise. It changes no source, learner, architecture action,
freshness rule, mean-null ID or wealth arithmetic. A smaller B requires a
separately registered procedure; it does not change a completed experiment.

## 1. The actual obstruction

The completed n8 likelihood study matches the adaptive reference posterior
at all 256 forecast cuts, yet waits 30–54 fresh labels before installation.
Its B=6 and bet fraction 3/4 give coefficient 1/8. The earlier
[filtration result](PERSISTENCE_FILTRATION_GEOMETRY.md) rules out improving
this by choosing a context-specific coefficient under the same pre-context
mean-null. A common B=13/8 is suggested by the likelihood bank and successful
AMP closeness, but closeness on passed queries alone does not establish the
mathematical score on a failing next attempt.

The original Runtime admission instead proves a class-wide bound from the
positive base and normalizer cap. Binary base one and R=16 yield K=15 and
require B >= log 15. It therefore refuses 13/8 even when the owned baseline
is exactly uniform and the actual candidate has much smaller mass ranges.
The needed information is already present in each predictor's paid,
whole-domain native mass enclosures.

## 2. A sharp probability-box law

At a fixed complete pre-context history, let each domain row r cover a set
of legal next contexts. For predictor a, every label y has positive bounds

`0 < L[a,r,y] <= m[a,y](x) <= U[a,r,y]` for every x covered by r.

The proper probability uses the exact sum of the mathematical predictor's
stored masses, not its separately rounded division output. Define

`ell[a,r,y] = L[a,r,y] / (L[a,r,y] + sum(z != y) U[a,r,z])`,

`u[a,r,y] = U[a,r,y] / (U[a,r,y] + sum(z != y) L[a,r,z])`.

Then `ell <= p <= u`. To prove this, hold the other masses fixed: the
normalized probability increases with its own mass and decreases with each
other mass. Substituting the corresponding endpoints gives the two bounds.
They are attained at those corners of an independently variable rectangular
mass box. This is sharp for the declared box information, not necessarily
for a native graph whose masses have additional dependencies.

For candidate C and deployed D, aligned over the same complete source rows,
one common ratio bound is

`K = max(1, max(r,y) {u[C,r,y]/ell[D,r,y], u[D,r,y]/ell[C,r,y]})`.

Every legal next gain lies in `[-log K, log K]`. The same corner argument
shows sharpness for independently variable paired boxes. Correlations
between heads, predictors, sources or queues can only make this box proof
looser; no independence premise about actual data or native values is used.
Taking the maximum across every row happens before the random context.

A uniform baseline has exact mass box (1,1). If the candidate's two mass
coordinates lie in [1,9], its proper probabilities lie in [1/10,9/10],
and the common paired K is 5. A guarded rational upper enclosure proves
`log 5 < 13/8`. Reference point enclosures can be narrower still. Binary64
and AMP boxes use their own decoded positive base and rounded mass uppers;
no reference probability or successful-query tolerance replaces them.

## 3. Owned admission and refresh

Runtime retains the existing cheap class-cap proof when it succeeds. If
that proof is too loose for the immutable registered B, it prepays the box
calculation and a new exact log enclosure. Its inputs are exclusively:

* current reference candidates' retained `RangeBound.masses`;
* current binary64 enclosures' exact decoded base and stored mass uppers;
* current CUDA enclosures' positive base and stored mass uppers for the
  declared deterministic mixed schedule.

The latter two already cover the entire source domain and all legal delayed
queue values, and bind current master encodings. Complete row and label
coverage is checked. The scalar helper accepts no context, target or caller
certificate at an owned endpoint and grants no authority by itself.

Admission records `ratio_bound_kind=current-native-mass-box` when using
this refinement. This distinguishes a proof about current masters from the
old class-cap proof that survives all range-safe updates. The bound and its
scope are retained in the same paid identity. Alpha is allocated before
fallible proof work; failed admission keeps the debit.

Every event is scored with the bound established before its context. While
the identity remains ACTIVE, Runtime derives a bound for the complete staged
successors before publishing the next idle boundary. Updated physical
masters first receive their ordinary whole-domain range proofs. An
unproved/over-budget new gain bound stops that identity before next ingress,
even when ordinary execution and the broader native range remain valid.
No later favorable event resumes it. A crossed statistic stays stopped;
its ordinary lineage and all installation guards continue to be checked.

The native enclosures concern mathematical forecast functions on **all**
next contexts, including a next attempt whose kernel, reference relation or
storage fails. Actual accepted CUDA forecasts still require exact schedule
conformance and the separate AMP relation. Thus the bound does not condition
on successful computations or select only favorable contexts.

For each live attempted slot, its existing stopped statistic has a bounded
current gain; after termination the remaining slots are zero. The existing
conditional stopped-epoch mean-null and nonnegative linear-factor proof
therefore apply, with the original downward wealth grid. This does not infer
a producer law from a fixture, transfer a reference rejection to AMP, or
substitute an uninterrupted/differently stopped H>1 epoch-null for the
actual declared stopped statistic. Larger coefficients have larger adverse
losses and need not dominate the old coefficient in finite-horizon power.
