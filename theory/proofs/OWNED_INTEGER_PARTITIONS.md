GATE REGISTERED, NOT EXECUTED.** This is a realization of the same complete
indexed learner. No architecture action, Foundation definition, ERC-1 rule

The [direct-partition proof](DIRECT_INTEGER_PARTITION_READOUT.md) removes
the transient energy-coefficient representation when the current native

integers with the same elimination geometry and a29-word mixed-precision

## 2. Actual storage, preflight and work

Let D=n(n-1)/2 and w=ceil(min(I,n+4S)/8). Runtime prepays and pins one
`direct_integer_partition_workspace` of exactly

    W = (C+2)w bytes.

The first C cells hold live tables, joins and reductions; the final two
hold the partition roots. The owner keeps its permanent memoryview export.
Each call borrows a separate view, so releasing it cannot unpin or resize
the paid extent. The existing forward compaction argument applies: retain
table descriptors in increasing source order and copy each cell toward a
destination no greater than its source. At most(n-1)C cell moves are added.

Native count/type/query, span, bit and complete table-shape preflights run
before clearing any old byte. Intermediate table and root integers obey
n+4H bits. Factor powers use explicit most-significant-bit binary powering;
at most2D*bit_length(S) products suffice at the declared cap. No wide table
value tuple or world list substitutes for the owned byte extent.

With B=2D*bit_length(S), the conservative prepaid scalar/index/byte tariff is

    64(n+1)^2(D+n+1) +32[W+(A+nC+B+D+16)(n+1+w)].

Reference readout separately debits128(D+n+4H+16). The physical path prepays
two constructions,1024(n+4S+1) and128(n+1)output_cap, besides the existing
arena, frame and relation charges. These are declared tariffs, not CPU
instruction counts or bigint multiplication-time laws. Bounded operands,
byte conversions, descriptors and Python temporaries also occupy host
memory covered by the whole-job contract; W is not a whole-heap bound.

At the component registration C1024/S396/I32768, the actual W is211356
bytes at n64 and235980 bytes at n256. At small n the base9 cell width can
exceed the old packed-coefficient width. No uniform resource or throughput
dominance is claimed.

The plan retains complete before/query, span, both exact roots, table shape,
integer envelope, maximum integer width, compaction count and bit limit.
Every field is reconstructed and checked with exact types. Even a common
rescaling of both roots, which preserves their ratio, is not the exact
integer plan registered by this construction. Immutable old plans and
sealed frames retain their original values after later workspace reuse.
