# The existing hierarchy and its identification limits on actual AMP

Status: **all five target cases executed and independently audited, 2026-09-13.**
The target audit uses the same fixture, native decision class and empirical
upper as [the Reference experiment](SATURATED_REFERENCE_CLASS_BOUND.md).
It adds no task oracle, source primitive, architecture action or static
resource family. Foundation R4, XVII.31 and ERC-1 remain frozen.

## 1. What the target experiment decides

The n-token task presents one-hot tokens at two positions. The hidden binary
assignment belongs to the external producer and independent evaluator;
only ordinary context bytes and noisy labels enter Runtime. The immutable
initializer is `(1,8)`, the update unit is ten and the learning rate is zero.
Each training path edge receives nine majority and one minority labels.
These are declared constructor endpoints, not freely fitted parameters.

`fixture_parameters` supplies the same pure registration and streams to
both CPU and CUDA audits before constructing any Runtime. The CUDA version
registers `CudaCompilerPolicy`, separately allocated reference/CUDA rules,
owned resident installation, the actual device identity and a live 4 GiB
Windows host contract. The same broad native grammar includes the smaller
SUM-only competitor and full token-pair lookup alternatives. It is not
restricted to the relation solver's proposed shape.

At the training boundary, the paid empirical-relation solver proposes group
SUMs and four PRODUCT cells. Its owned constructed witness attains the
universal categorical training upper. `BoundedReferenceProof` therefore
closes the historical **reference initializer/profile endpoint comparison**
over the registered native class plus baseline. The unexecuted syntax cursor
is neither exhausted nor relabelled as an enumeration. This is not a proof
of optimality over target AMP parameters, future data or Compiler policies.

The subsequent ordinary stream drives four continuous reference/CUDA
learners, separate fresh wealth and owned installation. The optional CPU
binary64 learners also execute continuously as an independent numerical
control. None supplies CUDA forecasts, wealth or successor state. The
[owned target run](OWNED_CUDA_POLICY_RUN.md) subsequently seals its declared
finite horizon while retaining the final partial optimizer unit.

## 2. Why this particular forward map is numerically simple

For the selected `(1,8)` endpoint, each group SUM and each PRODUCT is zero
or one throughout the complete one-hot domain. Exactly one PRODUCT cell
is active. The readout excesses are zero and eight, so the retained masses
are exactly one and nine and their normalizer is exactly ten. All these
intermediates are representable in both binary16 and binary32. The declared
ordered half/single arithmetic is exact up to the final binary32 division;
its output is the rounded pair `(1/10,9/10)` in the selected label order.

Thus this fixed endpoint does not need cancellation, growing coefficients,
small subnormals or a precision-changing rewrite. This argument concerns
its actual native graph and parameters; it is not a general AMP bound for
every member of the broad native class. Runtime still executes its complete
state/prediction relations, whole-domain range admission and exact raw
forecast checks. The independent final audit replays every retained CUDA
phase with a separate exact rounded interpreter, including gradients and
commits despite the declared zero learning rate. Reference predictions
are independently checked at every one of the n-squared domain contexts;
this count is not advertised as that many new device observations.

## 3. The strong negative controls survive the bridge

A smaller SUM-only graph sends each observed left token to its empirical
majority-label readout at weight eight. These labels are derived from the
legally revealed training counts, without hidden task bits. On the four-token
path it has five nodes, two SUMs, three edges and zero PRODUCTs, versus the
hierarchy's eighteen nodes, six SUMs and four PRODUCTs. It belongs to the
same native class and reaches the same exact training upper.

The target control constructs both learners through Runtime and repeats the
revealed training contexts as subsequent ordinary events. Their **actual
binary32 forecast words agree** on those contexts. This is stronger than a
float64 rescore of a proposed graph, and refutes any inference from either
the reference optimum or its AMP execution to necessary PRODUCT structure.
This diagnostic construction runs in explicitly manual mode; it grants no
owned policy-run or install authority.

For disconnected training edges `(0,1)` and `(2,3)`, hidden assignments
`(0,1,0,1)` and `(0,1,1,0)` yield identical ordinary training and subsequent
audit data but opposite unseen relation `(0,2)`. The retained proposals and
empirical objective agree. Fresh comparison with the deployed baseline on
that same observable stream cannot resolve the missing component relation.
Neither an installation nor a valid comparison crossing identifies a full
unobserved conditional table.

A connected but misleading training path is the other existing control:
flip the labels on its first edge, then return to the original producer for
fresh data. The empirical upper can still be attained by the wrong proposed
relation. Noncrossing at the finite horizon remains unresolved and cannot
be converted into a rejection theorem. The deterministic audit tape supplies
no proof of its external stochastic-law assumption.

The existing exact full-uniform-task lower for unrestricted unary SUM,
`[log(2)+H(0.1)]/2`, remains the strong analytic comparator; the hierarchical
conditional attains `H(0.1)`. These are known-task reference facts, distinct
from training identification and from a population result for arbitrary
quantized SUM executors. Subsequent model science must use competitive
implemented baselines with matched data and measured resources.

## 4. Executed evidence and resource scope

The n=32 run constructs the 74-node witness with six SUMs, four PRODUCTs,
68 weighted SUM edges and 76 total edges. Its broad native class contains
at least `2^6540` source-only strings. One feasible witness reaches the
universal reference training upper without enumerating that class.
Actual paired evidence permits installation at cursor 330; the learner
continues through 622 with two final partial-unit events. All **1,963 CUDA
and 1,963 binary64 phases** pass independent replay.

The misleading n=4 case retains its historical optimum and spent alpha but
seals unresolved without installation. Both disconnected worlds install at
40 and seal at 42, despite their opposite unseen relations. The smaller
SUM-only learner matches the hierarchy's actual forecast words on all 30
repeated training observations. Across the five workers, **2,701 CUDA and
2,701 binary64 phases** pass. This is finite executed evidence, not an
identifiability theorem derived from successful persistence.

Peak owned packed payload for n=32 is 313,552,643 bytes; the native arena
consumes 1,944,952 bytes of its preallocated 16 MiB. Its largest actual phase
record uses 28,865 of the declared 131,072 bytes, and its largest phase uses
431 of 4,096 output cells. The completed job peak, including the independent
final audit, is 3,905,241,088 bytes, below the original 4 GiB host cap. No
FP resource cap or execution semantics was changed to achieve this run.
