The Runtime chooses the fixed machine from these immutable declarations.
It accepts no supplied learner endpoint, inference plan, resource lease,

This machine implements that fixed reference family and its registered

## 2. Complete numerical projection and phase refinement

An owned learner stores C=(n,d,pending,cursor,steps), with all D signed
nonloop counts and both clocks. It additionally stores the three exact
pending gradient forms when a target has been observed. Counts include
every executed profile repetition. They are not restricted to ordinary
data or replaced by independent marginals. Delayed state is empty by the
registered G, and the complete accumulator has unit_count 0 or 1.

For native world k write

`W(k) = 9^(SUM_(i,j) |d_ij| * 1[z_i(k) XOR z_j(k) = 1[d_ij<0]])`.

With Z=SUM_k W(k), the complete parameter projection is theta_0=1 and
theta_(k+1)=W(k)/Z. Given the actual ordered query (i,j), let Z_y sum the
matching weights, E_y=8Z_y/Z and M_y=1+E_y. Every source, pair PRODUCT and
world indicator cache coordinate is an exact 0/1 value determined by the
ordered query and native index. The only other cache values are E_0,E_1;
the complete readout is (E_0,E_1,M_0,M_1,10,M_0/10,M_1/10).

After observing the independently owned target y, the gradient forms are

`(1/M_y - 1/5, 4/5 - 8/M_y, 4/5)`.

The first belongs to slot 0, the second to worlds matching the actual
pending event, and the third to other worlds. Thus a diagonal observation
retains its nonzero accumulator even when the parameters do not change.
At a committed boundary every accumulator coordinate is zero. Guarded
explicit readers materialize the original complete learner and Evaluation;
requesting K output coordinates still incurs an Omega(K) output cost.

**Refinement theorem.** For every finite admitted ordinary/profile trace
within the declared decoder, integer, work and residency allowances, the
projection of every completed initialization, prediction, observation,
commit and attachment is the corresponding exact native phase under the
same G/Gamma/U, ordered source values and independently acquired targets.

**Proof.** Initialization has d=0, so all K weights are 1/K and both
accumulators are empty. Positive partition elimination computes exactly
Z_0 and Z_1 by finite distributivity, with no dropped world or cancellation.
The cache/readout projection above is the literal native evaluation. The
native reverse derivative is exactly the three stated gradient forms,
including the fixed feature slot. The existing unit simplex update is
equivalent to d_ij <- d_ij + 1-2y for a nonloop observation, with unchanged
counts for a diagonal; the count encoding theorem proves this normalized
weight identity. In either case the commit clears the pending accumulator
and increments the optimizer clock. Observation increments the local
cursor first and retains its ordered query and target. A profile repeats
these same maps from Gamma, then attaches the resulting complete state to
the actual ordinary cursor without resetting its counts or optimizer
clock. Induction proves all the stated phase projections. The point
decoders recover every native coordinate, not only the current forecast.

The numerical induction does not identify complete Runtime roots or their
costs. Provenance, actual observations, role debits, retained traces,

## 3. Range, execution allowances and retained failures

All reachable count weights are positive and normalized. Consequently every
categorical cache activation is in [0,8], masses are in [1,9] and the
normalizer is exactly 10. A diagonal attains activation 8 and mass 9. The
range certificate binds the complete indexed declaration and categorical
domain; it quantifies over every count vector and domain row, without
expanding K slots or n^2 rows. The Runtime still pays for range admission
and revalidation. The finite activation basis (0,1,E_0,E_1) also preserves
the exact minimum nonzero activation, maximum activation and rational
encoding-width diagnostics over the full cache.

The registered arithmetic is
`indexed-literal-count-positive-natural-order-reference-v1`. It uses
natural anchored elimination order, at most 4096 join cells, 32768 live
integer cells and 2,000,000 positive table operations. The exact integer
envelope is at most min(32768, registered reference bits), with preflight
`n + 4*SUM |d| + 8` before powers or numerical tables. Retained counters
have a separate (2^62)-1 envelope. A compact exact expression may survive a
boundary whose next rational decoding is unfunded; no uniform inexpensive
inference claim follows from count storage.

The Runtime prepays planning work

`64*(n+1)^2*(D+n+1) + 128*(D+n+1)`.

After metadata preflight determines the exact table multiplication/addition
counts P and S, it separately prepays

`32*(n+1)*(P+S) + 64*(D+8) + 64`

before entering numerical execution. The schedule counts are checked
against the executed decoder. These are declared reference work tariffs
covering table scalar operations, bounded projection/index visits, guarded
power formation and phase metadata. They are not elapsed time, arbitrary
precision bit/GCD cost or total Python heap. The unused table allowance is
not charged as if executed. The debit role comes from the existing ordinary
candidate or profile path; no public action supplies that role or a callback.

As with the existing reference machine, actual retained packed buffers are
admitted by the Runtime's lease allocator, with coexistence, trace history
and failure records charged. `reference_payload_bytes` is this retained
packed resource, not total process RAM, decoder scratch or device memory.
Code, Gamma, U, machine identity and source domain are bound in the owned
manifest. No complete physical certificate is inferred from the tariffs.

Ordinary input still enters through prepaid byte ingress. Predictions lock
the root; only the actual target observation can proceed. Profiles consume
registered, already revealed observation identities and pay for repeated
uses. The existing staging protocol retains local completed phases before
publishing all candidate successors. If a later candidate fails, earlier
local commits remain in the trace, all observed states and the actual
target survive, and no published learner advances. Spent work and received
ingress are retained. There is no rollback to a fictitious cheaper past.

The star audit illustrates the precise solver boundary. Thirteen actual

center. A following query (2,3) makes natural elimination try a 16384-cell
join and refuses before decoding. This tree admits a much better order;
the refusal is not a lower bound for all inference algorithms or a reason
